# 큰길브리지 데모 열람 알림 서버 설치 (Google Apps Script)

우리가 만들어 보낸 데모 사이트를 **누가 열어봤는지** 알려주는 서버입니다.

| | 없을 때 | 설치 후 |
|---|---|---|
| 문자 20통 보낸 뒤 | 누가 봤는지 모름 | **열는 순간 메일이 옴** |
| 전화 걸 곳 | 20곳 전부 | **열어본 5곳만** |
| 전화 첫마디 | "처음 뵙겠습니다" | **"보내드린 거 보셨더라고요"** |
| 우선순위 | 없음 | **두 번 이상 열어본 곳부터** |

> **이 서버가 죽어도 데모 사이트는 멀쩡합니다.** 알림만 안 옵니다.
> 고객 화면에는 아무 영향이 없습니다.

---

## ⚠️ 시작하기 전에 — 딱 하나만

**계약 서버 프로젝트에 붙여넣지 마세요.** 반드시 **새 프로젝트**를 만드세요.

전에 계약 서버에 다른 코드를 붙여넣어서 계약 서버가 멈춘 일이 있었습니다.
이건 완전히 별개의 서버입니다. 새로 만들면 무슨 일이 있어도 계약 서버는 안전합니다.

---

## 1) 스크립트 만들기 (3분)

1. **https://script.new** 접속 (새 프로젝트가 열립니다)
2. 프로젝트 이름을 **`큰길브리지 데모알림`** 으로 바꿉니다
3. 기본으로 열린 `Code.gs` 내용을 **전부 지우고** 이 폴더의
   **`큰길브리지-데모알림서버.gs`** 를 통째로 붙여넣습니다
4. 파일 이름도 **`큰길브리지-데모알림서버`** 로 바꿔두세요
   (나중에 열었을 때 무슨 서버인지 바로 알 수 있게)
5. 저장 (디스크 아이콘)

설정값은 손댈 것이 없습니다. 알림받을 주소가 이미 `gilauto325@gmail.com` 입니다.

## 2) 권한 주고 확인하기

편집기 위쪽 **함수 목록에서 `점검` 을 고르고 「실행」**.

권한 요청 창이 뜹니다. 드라이브와 메일을 쓰기 때문입니다.
"안전하지 않다"는 경고가 나오면 **고급 → 이동** 을 누르면 됩니다.

아래 실행 기록(로그)에 이렇게 나오면 성공입니다.

```
기록장 주소 : https://docs.google.com/spreadsheets/d/...
알림받을주소 : gilauto325@gmail.com
폴더        : 내 드라이브 > 큰길브리지 데모
여기까지 나왔으면 설치는 끝났습니다.
```

**이어서 `시험알림` 을 실행**하세요. 메일이 한 통 와야 합니다.
안 오면 스팸함을 보세요.

## 3) 배포하기

**배포 → 새 배포 → 유형: 웹 앱**

| 항목 | 값 |
|---|---|
| 실행 사용자 | **나** |
| 액세스 권한 | **모든 사용자** |

> ⚠️ **"Google 계정이 있는 모든 사용자"는 안 됩니다.**
> 이름만 보면 될 것 같은데, 고객이 데모를 열 때 **로그인 창을 만나** 알림이 안 옵니다.
> 반드시 **`모든 사용자`** 여야 합니다.

배포를 누르면 **웹 앱 URL** 이 나옵니다. `.../exec` 로 끝나는 주소입니다.
**그 주소를 저에게 주세요.** 제가 `demo-beacon.js` 에 박아 넣겠습니다.
그러면 형님이 다시 손댈 일이 없습니다.

## 4) 나중에 코드를 고쳤을 때 ← 여기서 많이 막힙니다

코드를 고치고 **저장만 하면 반영되지 않습니다.** 반드시:

**배포 → 배포 관리 → 오른쪽 위 연필(✏️) → 버전: `새 버전` → 배포**

「새 배포」를 또 누르면 **주소가 새로 생겨서** 예전 주소는 그대로 옛날 코드로 돕니다.
고칠 때는 **연필**, 처음 만들 때만 **새 배포** 입니다.

---

## 어디에 무엇이 쌓이나

**내 드라이브 > 큰길브리지 데모 > 데모 열람 기록** (구글 시트)

두 장으로 되어 있습니다.

### 「업체별」 장 — 이게 영업 명단입니다

| 상호 | 전화 | 방문 | 총 머문 시간 | 최장 한 번 | 끝까지 본 횟수 | 마지막 방문 |
|---|---|---|---|---|---|---|

**전화 걸 순서를 정하는 표입니다.** 방문 많은 순, 머문 시간 긴 순으로
정렬해서 위에서부터 걸으시면 됩니다. 휴대폰 구글시트 앱에서도 보입니다.

### 「열람」 장 — 일어난 일 전부

한 줄 한 줄 다 남습니다. 어느 문구를 보낸 날 열람이 많았는지 나중에 대조할 때 씁니다.

---

## 메일이 언제 오나

- **열었을 때만** 옵니다. 보고 있는 동안 계속 오지는 않습니다.
- 같은 업체가 **30분 안에** 또 열면 다시 보내지 않습니다.
- 하루 **30통**까지만 보냅니다 (봇이 긁어도 메일함이 안 터지게 하는 안전장치)

## 내가 볼 때는 알림이 안 오게

데모 주소 뒤에 **`?me=1`** 을 붙여 한 번 열면, 그 기기는 그 뒤로 계속 조용합니다.

```
https://www.ai-make.co.kr/demo/한아름/?me=1
```

형님 휴대폰과 컴퓨터에서 각각 한 번씩 해두세요.
안 해두면 **형님이 확인할 때마다 형님한테 메일이 옵니다.**

되돌리려면 `?me=0` 을 붙여 열면 됩니다.

## 영업 시작 전에

`시험알림` 으로 만든 기록을 지우고 시작하세요.
편집기에서 **`시험기록지우기`** 를 실행하면 됩니다.
