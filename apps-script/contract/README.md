# 큰길브리지 전자계약 서버 설치 (Google Apps Script)

`contract.html` 이 쓰는 무료 백엔드입니다. 설치하면 이렇게 됩니다.

| | 서버 없을 때 | 서버 설치 후 |
|---|---|---|
| 고객 링크 | 아주 긴 주소 (700자 이상) | **짧은 주소** `contract.html?c=ABCD1234&s=…` |
| 서명 후 PDF | 고객이 직접 저장 | **자동 생성 → 내 드라이브에 보관** |
| 서명 통보 | 고객이 문자로 알려줌 | **양쪽 이메일로 PDF 자동 발송** |
| 계약 관리 | 없음 | **구글시트 계약 대장 자동 기록** |

> **서버 없이도 계약은 됩니다.** 설치는 편의 · 관리용입니다.
> 서버가 죽어도 긴 링크로 자동 전환되니 계약이 막히지 않습니다.

---

## 1) 스크립트 만들기 (5분)

1. **https://script.new** 접속 (새 프로젝트가 열립니다)
2. 프로젝트 이름을 **`큰길브리지 전자계약`** 으로 바꿉니다
3. 기본 `Code.gs` 내용을 **전부 지우고** 이 폴더의 **`Code.gs`** 를 통째로 붙여넣습니다
4. 위쪽 설정값을 확인합니다
   - `COMPANY_EMAIL` — 서명본을 항상 받을 주소 (기본 `gilauto325@gmail.com`)
   - 나머지는 그대로 두어도 됩니다
5. 저장(디스크 아이콘)

## 2) 배포하기

**배포 → 새 배포 → 유형: 웹 앱**

| 항목 | 값 |
|---|---|
| 실행 사용자 | **나** |
| 액세스 권한 | **모든 사용자** |

> ⚠️ **"Google 계정이 있는 모든 사용자"는 안 됩니다.**
> 이름만 보면 될 것 같지만 고객이 **로그인 창을 만나** 서명을 못 합니다.
> 반드시 **`모든 사용자`** 여야 합니다.

권한 승인 창이 뜹니다. 드라이브와 메일을 쓰기 때문입니다.
"안전하지 않다"는 경고가 나오면 **고급 → 이동** 을 누르면 됩니다.

배포를 누르면 나오는 **웹 앱 URL** 을 복사합니다.

```
https://script.google.com/macros/s/AKfyc.../exec
```

## 3) 계약서에 연결

`contract.html?admin=1` 을 열고 →
맨 아래 **계약 정보 → 서명 요청 서버** 칸에 그 주소를 붙여넣습니다.

한 번 넣으면 그 계약서 링크에 같이 담깁니다. **새 계약을 쓸 때마다 다시 넣어야 합니다.**
자주 쓰신다면 주소를 메모장에 저장해 두고 복사해 쓰세요.

## 4) 잘 되는지 확인

웹 앱 URL 을 브라우저 주소창에 그냥 넣어보세요. 이렇게 나오면 정상입니다.

```json
{"ok":true,"service":"keungil-bridge-contract","version":1,...}
```

## 만들어지는 것

내 구글 드라이브에 이렇게 쌓입니다.

```
큰길브리지 계약서/
├── 계약 대장                     ← 구글시트. 계약 하나당 한 줄
├── _data/                        ← 계약 내용 원본 (건드리지 마세요)
│   └── ABCD1234.json
└── 2026/
    ├── 홈페이지제작계약서_KB-20260828-739_바닐라헤어.pdf
    └── 서명_KB-20260828-739_김바닐.png
```

**계약 대장** 에는 계약번호 · 사이트 · 도메인 · 요금제 · 상호 · 담당자 · 금액 ·
월 관리비 · 오픈예정 · 서명자 · 서명시각 · PDF 링크 · 문서확인코드가 기록됩니다.

---

## 문서 확인 코드

계약 내용으로 만든 지문 같은 것입니다.
고객 화면과 서버가 **각각 따로 계산해서 맞춰봅니다.**
값이 다르면 대장에 **"확인코드 불일치"** 로 남습니다.
나중에 "내가 서명한 내용과 다르다"는 다툼이 생겼을 때 근거가 됩니다.

---

## 코드를 고친 뒤에는

**배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**

- 연필로 수정 → **주소 그대로 유지** ✅
- 새 배포 → **주소가 새로 발급됨** ❌ (계약서에 넣은 주소를 다시 바꿔야 함)

---

## 주의할 것

**요금이 바뀌면 두 곳을 같이 고쳐야 합니다.**
`contract.html` 의 `PLANS` · `OPTIONS` 와 `Code.gs` 의 `calcTotal_()` 은
**같은 방식으로 금액을 계산해야** 합니다. 한쪽만 고치면 계약서 금액과
메일 · 대장의 금액이 어긋납니다.

**메일 한도** — 지메일 계정은 하루 100통까지 보낼 수 있습니다.
계약서 발송은 한 건에 1통이라 넉넉합니다.

**이미 서명된 계약** 에 다시 서명하면 덮어쓰지 않고 기존 것을 돌려줍니다.
다시 서명받아야 한다면 `Code.gs` 의 `ALLOW_RESIGN` 을 `true` 로 바꾸세요.
