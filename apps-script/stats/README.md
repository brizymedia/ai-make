# 유입 기록 서버 — 설치 (5분)

큰길브리지 · 큰길이벤트 · 이벤트 코리아 세 사이트의 방문을 한 시트에 모으고, **현황판** https://www.ai-make.co.kr/stats/ 에서 봅니다.
검색(네이버·구글·다음·AI)에서 얼마나 들어오는지, 어디서 들어왔는지, 어느 페이지를 보는지, 문자·카톡으로 보낸 링크가 얼마나 눌리는지.

## 1. 서버 만들기

1. https://script.new → 프로젝트 이름 **「큰길브리지 유입」**
2. `큰길브리지-유입서버.gs` 내용을 통째로 붙여넣기 (기존 내용 지우고)
3. **프로젝트 설정(톱니) → 스크립트 속성 → 속성 추가**
   | 속성 | 값 |
   |---|---|
   | `STATS_KEY` | 현황판 열쇠. 아무 글자 12자 이상 (예: 영문+숫자 섞어서). 이걸 아는 사람만 현황판을 봅니다 |
4. 편집기에서 함수 **「점검」** 고르고 ▶ 실행 → 권한 승인 → 로그에 「기록 시트 : https://docs.google.com/…」 가 나오면 완료
   (내 드라이브에 「큰길브리지 유입」 폴더와 「유입 기록」 시트가 생깁니다)
5. **배포 → 새 배포 → 웹 앱** · 실행 사용자 **나** · 액세스 **모든 사용자** → 배포
6. 나온 **/exec 주소**와 **STATS_KEY** 를 저에게 → 제가 `stats/stats.js` 와 현황판에 박습니다. 그 뒤부터 기록이 쌓입니다.

열쇠는 카톡·메일로 보내지 말고 직접 불러 주세요. 이 문서나 코드에도 적지 않습니다.

## 2. 현황판 보는 법

https://www.ai-make.co.kr/stats/ → 처음 한 번 열쇠 입력(브라우저가 기억) → 기간(오늘·7일·30일·90일)과 사이트 탭.

- **검색 유입** = 네이버 검색 + 구글 검색 + 다음 검색 + 기타 검색 + AI 검색(챗GPT·퍼플렉시티·제미나이 등)
- **직접 · 카톡 · 문자** = 주소를 직접 쳤거나, 카톡·문자 링크를 눌러 온 방문. 카톡·문자는 「어디서 왔다」는 정보를 안 보내 줍니다.
  → 내가 보내는 링크에는 **utm 을 붙이세요**. 현황판 아래 「링크 만들기」로 만들면 됩니다. 예)
  `https://www.ai-make.co.kr/?utm_source=sms&utm_campaign=demo0905` → 현황판에 「문자 링크 · demo0905」로 잡힙니다.
- 내 방문을 빼려면 각 사이트를 **`?me=1`** 붙여 한 번 열어 두세요 (그 브라우저는 이후 기록 안 됨).
- 집계는 5분 캐시. 「새로고침」은 캐시를 건너뜁니다.
- 검색어는 요즘 검색엔진이 안 넘겨줘서 거의 안 잡힙니다. 검색어까지 보려면 다음 단계로 **구글 서치콘솔 연결**이 필요합니다(형님 계정).

## 시트

「유입 기록 / 방문 기록」 — 시각 · 사이트 · 경로 · 제목 · 유입 · 출처 · 검색어 · utm_source · utm_medium · utm_campaign · 기기 · 방문자 · 새방문 · 언어 · 화면폭
방문자는 브라우저마다 붙는 무작위 번호입니다. IP·이름·전화는 없습니다.
한 해 10만 줄쯤 쌓이면 집계가 느려지니 그때 지난해 줄을 다른 시트로 옮기면 됩니다(제가 합니다).
