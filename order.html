접수되었습니다. 감사합니다.

홈페이지 주문서가 큰길브리지에 들어왔습니다. 이제 이렇게 진행됩니다.

  1. 이메일 접수 — 지금 저희 메일로 들어왔습니다. 확인하면 문자 한 통 드립니다.
  2. 기획서 · 데모 작성 — 적어 주신 내용으로 기획서 한 장과 실제로 열리는 데모 홈페이지를 만듭니다. 자료 받은 뒤 3~4일.
  3. 전달 · 확인 — 링크로 보내드립니다. 휴대폰으로 보시고 고칠 것을 말씀해 주세요.
  4. 견적서 · 계약서 — 확정된 구성으로 견적서와 전자계약서를 보냅니다. 링크에서 손가락으로 서명하시면 됩니다.
  5. 서명 → 양측 전달 — 서명본 PDF 가 두 분 메일로 자동 발송됩니다. 선금 입금 뒤 제작에 들어갑니다.
  6. 오픈 · 완료 — 도메인 연결과 검색 등록까지 마치고, 글자 · 사진을 직접 고칠 수 있는 열쇠를 드립니다.
