글쓰기 도구

사례 정보만 넣으면 갤러리 글(HTML) · 네이버 블로그 글 · 인스타 문구를 한 번에 만듭니다. 지역과 서비스를 자동으로 감지해 검색 키워드가 자연스럽게 들어갑니다. 이 페이지는 검색에 노출되지 않습니다.

01사례 정보

팁 · 상호에 지역명이 들어가면 제목이 훨씬 잘 걸립니다. 매번 같은 문장이면 저품질로 볼 수 있으니 "그날 이야기" 칸은 꼭 직접 쓰세요. 숫자가 있으면 넣으세요 — 검색과 AI가 제일 좋아하는 재료입니다.

02결과

갤러리에 올리는 순서
1. 「HTML 파일 내려받기」 → gallery/posts/ 폴더에 저장 (파일명 그대로)
2. 「목록 카드 복사」 → gallery/index.html 의 <div class="glist"> 맨 위에 붙여넣기
3. node build-sitemap.js 실행 후 커밋·푸시
또는 이 결과를 저에게 주시면 제가 올려드립니다.
