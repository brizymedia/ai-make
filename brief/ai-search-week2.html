출처: code.claude.com 공식 문서 — 「코드를 읽고 파일을 수정하고 명령을 실행하는 에이전트형 코딩 도구」
Claude Code를 한 줄로 말하면, 내 컴퓨터 폴더 안에서 파일을 읽고, 고치고, 새로 만들어 주는 AI 직원입니다. Anthropic이라는 회사가 만들었고, 공식 설명은 「코드를 읽고 파일을 수정하고 명령을 실행하는 도구」입니다. 이름에 코드가 들어가서 개발자용 같지만 겁먹지 않으셔도 됩니다. 여러분 홈페이지도 결국 파일 묶음이고, 블로그 글도 글자 파일입니다. 그래서 「연락처 바꿔 줘」, 「후기를 블로그 글로 써 줘」 같은 말로 일을 시킬 수 있습니다.

Claude Code

출근한 직원

서류함(폴더)에서 직접 꺼내 보고 고칩니다. 고치기 전에 「이렇게 고칠게요」 하고 확인받게 할 수 있어요.

파일내가 복사·붙여넣기폴더의 파일을 직접 읽고 씀
규칙 기억대화창마다 다시 설명CLAUDE.md에 적어 두면 매번 읽고 시작
안전장치해당 없음권한 모드 · 변경 확인 · 되돌리기
챗GPT 같은 대화창과 무엇이 다르냐. 대화창은 전화 상담원입니다. 말로 답은 해 주지만 내 서류함을 직접 열어 보지는 못합니다. 고칠 내용을 알려 주면 제가 복사해서 붙여넣어야 하죠. Claude Code는 사무실에 출근한 직원입니다. 폴더에서 파일을 직접 꺼내 보고 고칩니다. 다만 고치기 전에 「이렇게 고칠게요」 하고 내 확인을 받도록 할 수 있습니다. 그리고 규칙을 CLAUDE.md라는 문서에 적어 두면 매번 읽고 시작합니다. 오늘 이 두 가지 — 확인받기와 CLAUDE.md — 를 꼭 가져가시면 됩니다.

되돌리기의 한계

명령으로 삭제·이동한 파일은 되돌리기로 안 돌아옵니다. 그래서 백업.

1Reject — 적용 전이면 거절
2되돌리기 — 이번 대화에서 고친 것 (터미널: Esc 두 번 · /rewind)
3백업 폴더에서 복사해 덮어쓰기
4Git 변경 이력 (쓰는 경우)
일을 시켰는데 이상한 방향으로 가면 일찍 멈추는 게 가장 쌉니다. 정지 버튼을 누르면 바로 멈춥니다. 멈추지 않고 방향만 바꾸고 싶으면 「잠깐, 그 파일 말고 about.html에서 해 줘」처럼 입력하고 엔터를 치면 됩니다. 되돌리는 방법은 위에서부터 시도합니다. 아직 적용 전이면 Reject. 이미 적용됐으면 이번 대화에서 고친 걸 되돌리는 기능 — 터미널에서는 Esc 두 번이나 /rewind입니다. 그래도 안 되면 백업 폴더에서 복사해 덮어쓰기. 그리고 Git 이력. 꼭 기억하실 것 — Claude가 명령으로 파일을 지우거나 옮긴 건 되돌리기로 안 돌아옵니다. 그래서 백업이 제일 확실합니다.
