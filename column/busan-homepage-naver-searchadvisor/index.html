부산 홈페이지 네이버 등록, 서치어드바이저 순서대로 하기

2026-09-23 · 큰길브리지

부산 홈페이지 네이버 등록은 네이버 서치어드바이저 웹마스터도구에서 ① 사이트 등록 ② 소유확인 ③ 사이트맵 제출 순서로 하면 됩니다. 등록만으로 바로 검색에 나오지는 않습니다. 네이버 가이드에 따르면 검색로봇이 방문한 뒤 최대 1주일 안에 검색에 반영되고, 그 전에 robots.txt 와 noindex 설정이 로봇을 막고 있지 않은지 먼저 봐야 합니다.

핵심만 먼저
  • 서치어드바이저 사이트 등록은 호스트 단위(예: www.가게.com)로만 됩니다. 블로그 주소 뒤의 하위 경로는 등록 대상이 아닙니다.
  • 소유확인은 HTML 파일 업로드 또는 meta 태그 두 가지 방법 중 하나로 합니다.
  • 사이트맵 안의 주소는 소유확인한 사이트와 같은 도메인이어야 하고, 10MB · 5만 개 URL 제한이 있습니다.
  • 수집요청을 해도 실시간 방문은 아니며, 1일에서 몇 주까지 걸릴 수 있으니 매일 반복 요청할 필요가 없습니다.

1. 등록 버튼 누르기 전, 이 세 가지가 막고 있지 않나요?

네이버 검색로봇의 이름(User-Agent)은 Yeti 입니다. 홈페이지가 이 로봇을 막고 있으면 등록을 해도 수집이 되지 않습니다. 등록 전에 아래 세 가지를 먼저 확인하세요.

확인할 곳막혀 있는 모습고치는 방법
robots.txtDisallow: / 처럼 전체를 막음User-agent: Yeti 또는 * 에 Allow: / 로 허용
메인 페이지 meta 태그<meta name="robots" content="noindex">noindex 를 지움 — 표기된 페이지는 검색 반영에서 제외
방화벽 · 서버방화벽 설정이 로봇 접근을 차단로봇 접근 허용. 네이버는 IP 기반 차단 대신 robots.txt 사용을 권장
robots.txt 를 직접 고치기 어렵다면 제작업체나 개발자에게 'Yeti 허용 여부'를 물어보세요. 한 줄 설정이라 금방 확인됩니다.

2. 사이트 등록과 소유확인은 어떤 순서로 하나요?

  1. 서치어드바이저에 로그인하고 웹마스터도구로 들어갑니다.
  2. 사이트 주소를 입력합니다. 호스트 단위만 됩니다 — www.mysite.com, blog.mysite.com 은 되고 www.mysite.com/myid 같은 하위 경로는 안 됩니다.
  3. 소유확인 방법을 고릅니다. 제공되는 HTML 파일을 홈페이지에 업로드하거나, meta 태그를 메인 페이지 head 안에 넣는 방법 중 하나입니다.
  4. 파일이나 태그를 올린 뒤 '소유확인'을 누르면 끝입니다.

홈페이지 빌더를 쓰고 있어 HTML을 수정할 권한이 없거나 파일을 올릴 수 없다면, 네이버 가이드도 '사이트의 기술담당자에게 문의'하라고 안내합니다.

3. 소유확인이 계속 실패한다면 무엇을 보나요?

  • 메인 페이지가 자바스크립트나 meta refresh 로 다른 주소로 넘어가지 않나요? 네이버는 이 경우 지원이 안 된다며 HTTP redirect 방식을 쓰라고 안내합니다.
  • 소유확인 태그를 frame 태그 안에 넣지 않았나요? frame 바깥에 넣어야 합니다.
  • 내려받은 확인용 HTML 파일을 열어서 고치거나 이름을 바꾸지 않았나요? 원본 파일이 손상되면 확인이 안 됩니다.
  • 방화벽이 네이버 검색로봇을 막고 있지 않나요?

4. 사이트맵은 어떻게 제출하고, 무엇을 지켜야 하나요?

사이트맵(sitemap.xml)은 검색로봇에게 '우리 사이트에서 수집할 페이지 목록'을 알려 주는 파일입니다. 소유확인이 끝난 사이트를 누르고 요청 → 사이트맵 제출 메뉴에서 주소를 넣으면 됩니다. 새 글이 자주 올라오는 사이트라면 같은 메뉴의 RSS 제출도 함께 하면 좋습니다.

네이버 제출 조건내용
도메인 일치사이트맵 안 모든 URL이 소유확인한 사이트와 같은 도메인
용량10MB 이상이면 제출 불가
URL 개수사이트맵 하나에 50,000개 이상 담을 수 없음(넘으면 사이트맵 인덱스로 나눔)
응답 속도수집할 때 응답이 느리면 제출이 제한될 수 있음
주소 형식상대 경로 링크, 등록 사이트와 호스트가 다른 링크는 수집하지 않음

필수 요소는 페이지 주소(loc) 하나이고, 수정일(lastmod) 같은 항목은 선택입니다. 제작업체에 'sitemap.xml 이 자동으로 갱신되는지'도 함께 물어보세요.

5. 등록했는데 언제 검색에 나오나요?

네이버 가이드에 따르면 검색로봇이 방문한 뒤 최대 1주일 이내에 콘텐츠가 검색에 반영됩니다. 반영 여부는 네이버 웹문서 검색에서 site:가게주소 로 확인할 수 있습니다.

특정 페이지를 빨리 알리고 싶을 때 쓰는 '웹 페이지 수집요청'은 로봇이 실시간으로 오는 기능이 아닙니다. 우선순위에 따라 1일에서 몇 주가 걸릴 수 있고, 수집이 되어도 검색 노출까지 보장되지는 않는다고 네이버는 설명합니다. 같은 주소를 매일 다시 요청할 필요는 없습니다.

검색 노출을 늘리려고 같은 내용의 사이트를 여러 개 만들면 오히려 불이익을 받을 수 있다고 네이버 가이드는 경고합니다. 페이지마다 제목도 서로 다르게 써 주세요.

6. 부산 사장님이 같이 챙기면 좋은 공공 교육은?

부산광역시 소상공인활력증진센터 누리집에는 온라인 비즈니스 지원 공고가 올라옵니다. 9월 현재 '소상공인 디지털마케팅 실무교육 - AI 비즈니스 과정'(접수 2026.09.08~10.02), '2026년 제품사진 촬영지원'(접수 ~09.30), '2026년 소상공인 온라인마케팅 활성화 지원'(접수 ~10.31) 등이 게시되어 있습니다. 대상과 조건은 공고 원문에서 확인하세요.

홈페이지를 네이버에 등록한 뒤에는 사진과 소개 글이 검색 결과의 첫인상이 됩니다. 이런 교육과 촬영 지원을 함께 활용하면 등록 효과가 커집니다.

7. 혼자 하기 어렵다면

우리 홈페이지가 로봇을 막고 있는지, 사이트맵이 제대로 있는지 모르겠다면 무료 SEO 점검으로 먼저 확인해 보세요. 큰길브리지는 홈페이지 제작과 네이버 · 구글 검색 등록을 전국 비대면으로 진행합니다. 새로 만들거나 손봐야 한다면 제작 문의를 남겨 주세요.

자주 묻는 질문

네이버 스마트플레이스에 등록했는데 서치어드바이저도 해야 하나요?

역할이 다릅니다. 서치어드바이저는 홈페이지를 네이버 웹문서 검색에 알리는 도구입니다. 홈페이지가 있다면 따로 등록하는 것이 좋습니다.

소유확인은 HTML 파일과 meta 태그 중 무엇이 좋나요?

둘 다 네이버가 안내하는 방법입니다. 파일을 올릴 수 없는 빌더라면 meta 태그를, HTML 수정이 어렵다면 파일 업로드를 고르면 됩니다.

사이트맵을 제출했는데 페이지가 다 검색되지 않아요.

네이버는 사이트맵의 URL 가운데 내부 알고리즘으로 수집 대상을 골라 우선순위대로 수집합니다. noindex, nofollow, 자바스크립트만으로 된 링크가 없는지 함께 점검하세요.

수집요청은 몇 번 해야 하나요?

한 번이면 됩니다. 1일에서 몇 주가 걸릴 수 있어 같은 주소를 매일 요청할 필요는 없다고 네이버는 안내합니다.
