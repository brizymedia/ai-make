모바일 우선 색인은 구글이 홈페이지의 휴대폰 화면을 기준으로 내용을 읽고 검색에 올린다는 뜻입니다. 그래서 PC 화면에만 있고 휴대폰 화면에서 빠진 메뉴 · 가격표 · 영업시간은 구글 입장에서 없는 내용이 되기 쉽습니다. Google 검색 센터는 모바일 사이트가 데스크톱과 같은 콘텐츠를 담고, 같은 제목과 같은 robots 메타 태그를 쓰라고 안내합니다. 사장님이 할 일은 휴대폰으로 내 홈페이지를 직접 열어 PC 화면과 한 줄씩 비교하는 것에서 시작합니다.

핵심만 먼저
  • 구글은 휴대폰 화면 기준으로 홈페이지를 읽습니다. 모바일에서 빠진 내용은 검색에 반영되기 어렵습니다.
  • Google 검색 센터는 모바일 버전을 갖추라고 매우 강력히 권장하고, 구현 · 유지가 가장 쉬운 반응형 웹 디자인을 권합니다.
  • 모바일과 PC에 같은 내용, 같은 제목(heading), 같은 robots 메타 태그를 둡니다.
  • 버튼을 누르거나 클릭해야만 불러오는 주요 내용은 구글이 읽지 못할 수 있습니다.
  • 모바일 주소를 따로 쓴다면 Search Console 에서 두 버전을 모두 인증합니다.

1모바일 우선 색인은 사장님 홈페이지에 무슨 뜻인가요?

예전에는 구글이 주로 PC 화면을 읽고 검색 결과를 만들었습니다. 지금은 휴대폰 화면이 기준입니다. 손님 대부분이 휴대폰으로 검색하니 구글도 휴대폰에서 보이는 내용을 그 페이지의 내용으로 봅니다. Google 검색 센터의 모바일 우선 색인 권장사항 안내 요지는 모바일 버전 페이지를 꼭 갖추고, 그 안에 PC와 같은 내용을 담으라는 것입니다.

검색 센터는 휴대폰에 맞는 홈페이지를 만드는 방법을 세 가지로 나눕니다. 어느 방식이든 구글이 휴대폰 화면을 기준으로 읽는다는 점은 같습니다.

반응형주소 하나, 화면 크기에 맞춰 배치만 바뀜(검색 센터 권장)
동적 서빙주소 하나, 기기에 따라 다른 HTML 을 보냄
별도 URL모바일 전용 주소(예: m.주소)를 따로 운영

Google 은 이 가운데 반응형 웹 디자인이 구현하고 유지하기 가장 쉽다며 권장합니다. 주소가 하나이고 내용도 하나라서, PC에 메뉴를 고치면 휴대폰에도 그대로 바뀝니다. 내용이 어긋날 일이 적다는 것이 사장님 입장에서 가장 큰 장점입니다.

휴대폰 화면이 좁다 보니 제작할 때 '모바일에서는 숨기기'로 정리해 버리는 내용이 생깁니다. 아래는 소상공인 홈페이지에서 자주 보이는 경우입니다. '왜 문제인가'는 검색 센터 안내의 요지, 나머지는 일반 요령입니다.

3눌러야 보이는 내용은 왜 조심해야 하나요?

검색 센터는 클릭이나 터치 같은 사용자 동작이 있어야만 주요 콘텐츠를 불러오는 방식(지연 로드)을 쓰지 말라고 안내합니다. 구글은 페이지를 읽을 때 사람처럼 버튼을 눌러 보지 않기 때문입니다.

  • '메뉴 전체 보기' 버튼: 누를 때 서버에서 메뉴를 가져오는 구조라면, 처음 화면에 없는 메뉴는 구글에 안 보일 수 있습니다.
  • '후기 더보기' · '소개 더보기': 이미 페이지에 들어 있는 글자를 접어 둔 것인지, 누를 때 새로 불러오는 것인지 제작사에 물어봅니다.
  • 햄버거 메뉴: 메뉴 링크 자체는 페이지에 들어 있어야 합니다. 버튼을 눌러도 메뉴가 잘 열리는지는 모바일 햄버거 메뉴 버튼 점검 글에 정리했습니다.
사진 · 동영상을 화면에 가까워질 때 불러오는 것은 흔하고 괜찮은 방식입니다. 문제가 되는 것은 메뉴 · 가격 · 영업시간 같은 주요 내용을 사람이 눌러야만 불러오게 만든 경우입니다.

4제목과 robots 태그도 휴대폰과 PC가 같아야 하나요?

네. 검색 센터는 모바일과 데스크톱에서 같은 명확하고 의미 있는 제목(heading)을 쓰고, 같은 robots 메타 태그를 쓰라고 안내합니다. 화면에 보이는 글자뿐 아니라 보이지 않는 설정도 맞춰야 한다는 뜻입니다.

특히 robots 메타 태그의 noindex(검색에 올리지 말라는 표시)가 모바일 쪽에만 남아 있으면, 구글이 휴대폰 화면을 기준으로 읽기 때문에 그 페이지가 검색에서 빠질 수 있습니다. 제작 중에 임시로 넣어 둔 noindex 를 지우지 않은 경우가 흔합니다(일반 요령).

5내 홈페이지는 어떤 순서로 점검하나요?

제작사에 묻기 전에 사장님이 직접 해 볼 수 있는 순서입니다(일반 요령).

  1. 휴대폰으로 내 홈페이지 주소를 직접 엽니다. 주소창이 'm.' 으로 바뀌는지 보면 반응형인지, 모바일 주소를 따로 쓰는지 알 수 있습니다.
  2. PC 화면과 휴대폰 화면을 나란히 두고 메뉴 · 가격표 · 영업시간 · 주소 · 전화번호가 휴대폰에도 글자로 있는지 하나씩 체크합니다.
  3. '더보기' · '전체 보기' 같은 버튼을 누르기 전 화면에 주요 내용이 이미 들어 있는지 제작사에 확인합니다.
  4. 큰 제목과 소제목이 두 화면에서 같은 글자인지 봅니다.
  5. 전화 버튼이 손가락으로 누르기 편한지도 함께 봅니다. 모바일 전화 버튼 점검 글에 기준을 정리했습니다.
  6. Search Console 의 URL 검사로 구글이 본 화면을 확인합니다. 방법은 URL 검사와 색인 요청 글을 참고합니다.
  7. 모바일 주소를 따로 쓴다면 Search Console 에서 PC 주소와 모바일 주소를 둘 다 인증합니다.
가장 손이 덜 가는 해결책은 반응형으로 바꾸는 것입니다. 모바일 주소를 따로 운영하면 내용을 고칠 때마다 두 곳을 손봐야 하고, 한쪽만 고치는 실수가 생기기 쉽습니다.

6모바일 주소를 따로 쓰고 있다면 무엇을 더 보나요?

오래전에 만든 홈페이지 가운데는 PC용 주소와 'm.' 으로 시작하는 모바일 주소를 따로 운영하는 곳이 있습니다. 이 경우 검색 센터는 두 버전을 Search Console 에서 모두 인증하라고 안내합니다. 그래야 모바일 쪽에서 생긴 문제를 따로 확인할 수 있습니다.

  • PC에서 메뉴를 새로 올렸을 때 모바일 주소에도 같이 올라갔는지 봅니다.
  • 모바일 주소의 페이지 수가 PC보다 눈에 띄게 적다면 빠진 페이지가 있는지 확인합니다.
  • 휴대폰으로 PC 주소에 들어갔을 때 같은 내용의 모바일 페이지로 연결되는지 봅니다. 모든 페이지가 모바일 첫 화면으로만 가면 손님도 구글도 원하는 페이지를 못 찾습니다.

자주 묻는 질문

모바일 우선 색인이면 PC 화면은 신경 쓰지 않아도 되나요?

아닙니다. PC로 들어오는 손님도 있으니 PC 화면도 그대로 필요합니다. 다만 구글이 휴대폰 화면을 기준으로 읽으므로, PC에 있는 주요 내용이 휴대폰에도 똑같이 들어 있어야 합니다.

휴대폰에서 가격표를 접어 두면 검색에 불리한가요?

글자가 처음부터 페이지 안에 들어 있고 화면에서 접어 둔 것이라면 구글이 읽을 수 있습니다. 문제가 되는 것은 가격표를 아예 지우거나, 버튼을 눌러야만 새로 불러오게 만든 경우입니다.

반응형 홈페이지인지 어떻게 알 수 있나요?

휴대폰과 PC에서 주소가 똑같고, PC 브라우저 창을 좁혔을 때 배치가 휴대폰처럼 바뀌면 반응형일 가능성이 큽니다. 휴대폰에서 주소가 'm.' 으로 바뀐다면 모바일 주소를 따로 쓰는 방식입니다.

모바일 주소를 따로 쓰면 Search Console 에 어떻게 등록하나요?

Google 검색 센터는 별도 모바일 주소를 쓸 때 PC 버전과 모바일 버전을 Search Console 에서 모두 인증하라고 안내합니다. 각각 속성으로 추가해 인증하면 됩니다.
