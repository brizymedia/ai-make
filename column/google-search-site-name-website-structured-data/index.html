검색 사이트 이름이 도메인으로 뜰 때 — WebSite 구조화 데이터로 알리기

2026-11-23 · 큰길브리지 · 읽는 시간 약 7분
검색 사이트 이름구글 사이트 이름WebSite 구조화 데이터alternateName

구글 검색 사이트 이름이 가게 이름 대신 도메인으로 뜨거나 이상한 이름으로 나온다면, 홈페이지 첫 화면에 WebSite 구조화 데이터를 넣어 원하는 이름을 구글에 알리는 것이 공식 방법입니다. 필수 칸은 name(사이트 이름)과 url(홈페이지 주소) 두 개이고, 짧은 이름 · 영문 이름은 alternateName 에 적습니다. 다만 이름은 구글이 정하는 것이라 반영까지 며칠에서 몇 주가 걸리고, 그 사이에는 도메인이 대신 보일 수 있습니다.

핵심만 먼저
  • 구글에 원하는 사이트 이름을 알리려면 홈페이지에 WebSite 구조화 데이터를 넣습니다(Google 검색 센터).
  • 구조화 데이터는 하위 페이지가 아니라 사이트 홈페이지에 있어야 합니다.
  • 사이트 이름은 도메인 또는 하위 도메인마다 하나만 지원되고, 하위 폴더(예: /shop/) 단위 이름은 지원되지 않습니다.
  • 필수 속성은 name · url 이고, 널리 쓰는 약칭이나 짧은 이름은 선택 속성 alternateName 에 적습니다.
  • 리치 결과 테스트로는 사이트 이름을 확인할 수 없고, 반영까지 며칠~몇 주 걸립니다. 그동안은 도메인 이름이 대신 보일 수 있습니다.

1검색 결과에 가게 이름 대신 도메인이 뜨는 이유는 무엇인가요?

구글 검색 결과의 각 줄 위쪽에는 작은 아이콘(파비콘)과 함께 사이트 이름이 보입니다. 구글은 이 이름을 홈페이지의 여러 신호를 보고 스스로 정합니다. 그래서 신호가 부족하거나 서로 다르면 가게 이름 대신 도메인이 나오거나, 예전 상호 · 제작 업체 이름 · 첫 화면 배너 문구처럼 엉뚱한 이름이 붙기도 합니다(일반 요령).

Google 검색 센터의 「Google 검색의 사이트 이름」 안내 요지는 이렇습니다. 원하는 사이트 이름이 있다면 홈페이지에 WebSite 구조화 데이터를 추가해 선호를 알릴 수 있고, 구글이 그 이름을 쓰지 못할 때는 도메인 또는 하위 도메인 이름을 백업으로 보여 줍니다. 즉 도메인이 뜨는 것은 오류라기보다 '아직 확신할 이름이 없다'는 표시에 가깝습니다.

  • 홈페이지 제목(title)이 '홈' · 'Welcome' · 'index' 처럼 이름이 아닌 경우
  • 첫 화면 제목 · 로고 글자 · 공유용 이름이 서로 다른 경우(예: 한쪽은 한글 상호, 한쪽은 영문)
  • 상호를 바꿨는데 홈페이지 곳곳에 예전 이름이 남아 있는 경우
  • 가게 이름이 너무 흔한 일반 단어라 구글이 상호로 보기 어려운 경우
파비콘(검색 결과 옆 작은 아이콘)이 안 보이거나 엉뚱한 그림이 뜨는 것은 별개 문제입니다. 아이콘 쪽은 광주 파비콘 구글 검색 · apple-touch-icon 글에 정리해 두었습니다.

2title 태그 · 사이트 이름 · og:site_name 은 무엇이 다른가요?

셋 다 '이름'처럼 보여서 헷갈리지만 쓰이는 곳이 다릅니다. 아래 표는 홈페이지 운영자가 구분해 두면 좋은 일반 요령입니다.

구분어디에 보이나무엇을 적나(일반 요령)
title 태그검색 결과의 파란 제목 줄, 브라우저 탭페이지마다 다르게. 예: '메뉴 안내 | 가게 이름'
사이트 이름(WebSite 구조화 데이터의 name)검색 결과 위쪽, 파비콘 옆 작은 이름사이트 전체에 하나. 손님이 부르는 공식 상호
alternateName구글이 name 을 못 쓸 때 참고하는 다른 이름널리 쓰는 약칭 · 짧은 이름 · 영문 이름
og:site_name카카오톡 · 페이스북 등 링크 공유 미리보기사이트 이름과 같은 상호로 맞추기

핵심은 한 이름으로 맞추는 것입니다. 첫 화면 title 앞쪽, 로고 옆 글자, 공유 미리보기 이름, 구조화 데이터의 name 이 모두 같은 상호이면 구글이 그 이름을 고를 가능성이 높아집니다(일반 요령). 공유 미리보기가 예전 이름으로 남아 있다면 공유 미리보기가 안 바뀔 때 글을 참고하세요.

3WebSite 구조화 데이터는 어떻게 넣나요?

구조화 데이터는 구글이 읽기 쉬운 형식으로 '이 사이트의 이름은 무엇이다'라고 적어 두는 짧은 코드입니다. 보통 홈페이지 첫 화면의 head 부분에 script 태그(type 값 application/ld+json) 하나로 넣습니다. 넣을 내용은 아래 네 줄이 전부입니다.

  • @context 값: https://schema.org
  • @type 값: WebSite
  • name 값: 손님이 부르는 공식 상호(예: 큰길브리지)
  • url 값: 홈페이지 첫 화면 주소(예: https://도메인/)
  • alternateName 값(선택): 약칭이나 영문 이름 목록(예: 큰길, Keungil Bridge)
  1. 손님이 실제로 부르는 이름 하나를 정합니다. 간판 · 명함 · 네이버 플레이스 · Google 비즈니스 프로필 이름과 같게 맞춥니다.
  2. 홈페이지 첫 화면(루트 주소)에만 WebSite 구조화 데이터를 넣습니다. 하위 페이지에 넣어도 사이트 이름 용도로는 쓰이지 않습니다.
  3. name 에 공식 상호, url 에 홈페이지 주소, 필요하면 alternateName 에 짧은 이름 · 영문 이름을 적습니다.
  4. 첫 화면 title · 로고 글자 · og:site_name 도 같은 이름으로 맞춥니다.
  5. Search Console 의 URL 검사로 첫 화면 색인을 다시 요청하고, 며칠~몇 주 기다립니다.
주소 · 영업시간 같은 가게 정보는 WebSite 가 아니라 LocalBusiness 구조화 데이터의 몫입니다. 한 페이지에 둘 다 넣어도 되지만 역할이 다릅니다. LocalBusiness 쪽은 용인 구조화 데이터 LocalBusiness 주소 · 영업시간 글에 정리했습니다.

4하위 폴더나 지점별로 다른 이름을 쓸 수 있나요?

Google 검색 센터 안내 요지에 따르면 현재 사이트 이름은 도메인 또는 하위 도메인당 하나만 지원되고, 하위 디렉터리(하위 폴더) 수준의 사이트 이름은 지원되지 않습니다. 예를 들어 example.com/suncheon/ 과 example.com/yeosu/ 에 지점 이름을 따로 붙일 수는 없습니다.

주소 구조사이트 이름 따로 가능?참고(일반 요령)
example.com가능(하나)본점 · 대표 상호를 사이트 이름으로
shop.example.com(하위 도메인)가능(하위 도메인별 하나)온라인몰처럼 성격이 다른 사이트를 나눌 때
example.com/shop/(하위 폴더)지원 안 됨도메인의 사이트 이름을 같이 씀. 지점 이름은 각 페이지 title 로 구분

지점이 여러 곳이라면 사이트 이름은 대표 상호 하나로 두고, 지점 페이지는 title 을 '순천점 | 대표 상호'처럼 나누는 편이 현실적입니다. 하위 도메인으로 나누는 것은 관리할 사이트가 늘어나는 일이라 꼭 필요할 때만 권합니다(일반 요령).

5넣었는데도 이름이 안 바뀌면 어떻게 확인하나요?

안내 요지에 따르면 리치 결과 테스트에서는 사이트 이름을 지원하지 않습니다. 그래서 테스트 도구에 '사이트 이름' 항목이 안 나온다고 잘못 넣은 것은 아닙니다. 반영은 구글이 홈페이지를 다시 읽은 뒤에 이루어지고, 며칠에서 몇 주가 걸릴 수 있습니다.

  1. 첫 화면 소스 보기에서 WebSite 구조화 데이터가 실제로 들어갔는지, name · url 철자가 맞는지 확인합니다.
  2. url 이 실제 첫 화면 주소와 같은지 봅니다. www 유무 · http/https 가 다르면 맞춥니다.
  3. 첫 화면 title · 로고 · og:site_name 에 예전 이름이 남아 있지 않은지 봅니다.
  4. Search Console URL 검사에서 첫 화면 색인을 요청하고, 2~3주 뒤 상호로 검색해 다시 봅니다.
  5. 그래도 다르면 alternateName 에 짧은 이름을 더하고, 홈페이지 밖(비즈니스 프로필 · SNS 소개)의 이름도 같게 맞춥니다.

사이트 이름이 정리되면 다음은 검색 결과에 함께 보이는 사진입니다. 이미지 쪽은 홈페이지 이미지 검색 · alt 텍스트 · 파일 이름 글을 이어서 보세요.

우리 홈페이지 첫 화면에 구조화 데이터와 title 이 제대로 들어가 있는지 궁금하다면 무료 SEO 점검에 주소를 넣어 보세요. 큰길브리지는 홈페이지 제작과 검색 노출 정리를 전국 비대면으로 진행합니다.

자주 묻는 질문

구글 검색 결과에 가게 이름 대신 도메인이 뜨는 건 오류인가요?

Google 검색 센터 안내 요지에 따르면 구글은 사이트 이름을 정하지 못할 때 도메인 또는 하위 도메인 이름을 백업으로 보여 줍니다. 홈페이지에 WebSite 구조화 데이터를 넣어 원하는 이름을 알릴 수 있습니다.

WebSite 구조화 데이터는 모든 페이지에 넣어야 하나요?

아닙니다. 사이트 이름용 구조화 데이터는 사이트 홈페이지(첫 화면)에 있어야 합니다. 필수 속성은 name 과 url 이고, 약칭이나 짧은 이름은 alternateName 에 적습니다.

하위 폴더마다 지점 이름을 사이트 이름으로 쓸 수 있나요?

현재는 도메인 또는 하위 도메인당 사이트 이름 하나만 지원되고, 하위 폴더 단위 사이트 이름은 지원되지 않습니다. 지점은 각 페이지 제목으로 구분하는 것이 일반적입니다.

넣고 나서 얼마나 지나야 반영되나요?

구글이 홈페이지를 다시 읽은 뒤 반영되며 며칠에서 몇 주가 걸릴 수 있습니다. 리치 결과 테스트로는 사이트 이름을 확인할 수 없으니 기다린 뒤 상호로 검색해 확인합니다.
