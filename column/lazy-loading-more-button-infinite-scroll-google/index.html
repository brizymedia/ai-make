지연 로드더보기 버튼 검색 노출무한 스크롤 SEO페이지 나누기 주소

스크롤하거나 '더보기'를 눌러야만 나타나는 내용은 구글 검색에 보이지 않을 수 있습니다. Google 검색 센터는 구글 검색이 페이지와 상호작용하지 않는다고 안내합니다. 즉, 버튼을 누르거나 아래로 내려 보지 않습니다. 사진이 많은 메뉴판 · 시공사례 · 후기 페이지에 지연 로드를 걸었다면, 처음 열었을 때 구글이 무엇을 볼 수 있는지부터 확인해야 합니다. 무엇은 늦게 불러도 되고 무엇은 안 되는지, 목록을 페이지로 나눌 때 주소는 어떻게 붙이는지, URL 검사로 어떻게 확인하는지 정리했습니다.

핵심만 먼저
  • 지연 로드는 중요하지 않거나 화면에 아직 보이지 않는 내용을 나중에 불러오는 방식입니다. 속도에는 도움이 되지만 잘못 걸면 내용이 검색에서 빠질 수 있습니다.
  • Google 검색 센터의 권장 방법은 스크롤 · 클릭 같은 손님 동작에 기대지 않고 내용을 불러오는 것입니다. 구글 검색은 버튼을 누르지 않습니다.
  • 페이지를 열자마자 보일 가능성이 높은 첫 화면 사진 · 가게 이름 · 대표 메뉴에는 지연 로드를 넣지 않습니다.
  • 무한 스크롤로 목록을 이어 붙인다면 묶음마다 ?page=2 처럼 고유하고 바뀌지 않는 주소를 줍니다. ?date=yesterday 같은 상대적인 주소는 피합니다.
  • 마지막 확인은 Search Console URL 검사의 실제 URL 테스트로, 렌더링된 페이지에 모든 내용이 들어 있는지 보는 것입니다.

1지연 로드가 뭔데 구글에 안 보일 수 있나요?

지연 로드(영어로 lazy loading)는 화면에 아직 안 보이는 사진이나 내용을 처음부터 다 불러오지 않고, 필요할 때 불러오는 방식입니다. Google 검색 센터 「Fix Lazy-Loaded Website Content」(영문) 안내의 요지는 이렇습니다. 중요하지 않거나 보이지 않는 콘텐츠의 로드를 늦추는 것이 지연 로드이고, 잘 쓰면 성능과 사용자 경험에 도움이 되지만, 잘못 쓰면 구글이 그 내용을 보지 못할 수 있습니다.

핵심은 한 문장입니다. 구글 검색은 페이지와 상호작용하지 않습니다. 사람 손님은 '더보기'를 누르고 아래로 쭉 내리지만, 구글은 그렇게 하지 않습니다. 그래서 버튼을 눌러야만 나오는 시공사례 20건, 스크롤해야 이어 붙는 후기 목록은 구글 입장에서 없는 내용이 될 수 있습니다.

우리 홈페이지가 이런 구조인지 쉽게 아는 법(일반 요령): 페이지 아래쪽에 '더보기' 버튼이 있거나, 아래로 내리면 목록이 끝없이 이어지거나, 탭 · 아코디언을 눌러야 내용이 나온다면 이 글의 점검 대상입니다.

2어떤 페이지에서 문제가 자주 생기나요?

소상공인 홈페이지에서 자주 보이는 경우는 세 가지입니다(일반 요령).

  • 식당 · 카페 메뉴 페이지: 메뉴 사진이 많아 처음엔 6개만 보이고 나머지는 '더보기'로 불러옵니다. 계절 메뉴나 대표 메뉴가 뒤쪽에 있으면 검색에 안 잡힐 수 있습니다.
  • 인테리어 · 시공 업체 사례 페이지: 사례가 쌓일수록 무한 스크롤로 이어 붙입니다. 최근 사례만 보이고 지역명이 들어간 옛 사례는 구글이 못 볼 수 있습니다.
  • 병원 · 학원 후기 · 공지 페이지: 게시판형 빌더가 목록을 스크롤로 불러오면, 첫 묶음 아래 글은 링크조차 구글에 전달되지 않을 수 있습니다.

공통점은 손님이 검색해서 찾을 만한 내용이 버튼 뒤에 있다는 것입니다. 반대로 장식용 사진, 화면 맨 아래 인스타그램 피드처럼 검색과 상관없는 것은 늦게 불러도 괜찮습니다.

3무엇은 늦게 불러도 되고, 무엇은 안 되나요?

Google 검색 센터는 페이지를 열자마자 보일 가능성이 높은 콘텐츠는 늦게 불러오지 말라고 안내합니다. 이 기준과 소상공인 홈페이지 사정을 합쳐 정리하면 아래와 같습니다. 왼쪽 열의 구분은 일반 요령입니다.

요령은 사진은 늦게, 글자와 링크는 처음부터입니다. 사진 파일은 무거워서 늦게 불러도 속도에 이득이 크고, 글자와 링크는 가벼워서 처음부터 넣어도 부담이 적습니다. 유튜브 퍼가기를 늦게 불러오는 방법은 홈페이지 영상 넣기 — 유튜브 퍼가기 · 지연 로드 · 자동재생 글에 따로 정리했으니 여기서는 반복하지 않습니다.

첫 화면의 큰 대표 사진까지 늦게 불러오게 하면 구글에 안 보일 수 있을 뿐 아니라, 손님 화면에서도 사진이 한 박자 늦게 떠서 오히려 느려 보입니다. 빌더가 '모든 이미지 지연 로드'를 기본으로 켜 두었다면 첫 화면 사진만이라도 끄는 설정이 있는지 확인하세요.

4'더보기' · 무한 스크롤 목록은 주소를 어떻게 나누나요?

목록이 길어서 무한 스크롤을 쓰고 싶다면, Google 검색 센터의 안내 요지는 각 묶음에 고유하고 지속적인 URL을 주라는 것입니다. 예를 들어 시공사례 목록이 12번째 묶음까지 있다면 그 묶음만 따로 열리는 주소(예: /cases?page=12)가 있어야 합니다. 그래야 구글이 묶음 하나하나를 주소로 찾아갈 수 있습니다.

또 하나는 상대적인 주소를 쓰지 말라는 것입니다. ?date=yesterday(어제) 같은 주소는 날마다 가리키는 내용이 바뀌어서 구글이 같은 주소에서 다른 내용을 보게 됩니다. 페이지 번호나 실제 날짜처럼 시간이 지나도 같은 내용을 가리키는 주소를 씁니다.

  1. 목록 페이지 맨 아래에서 '더보기'를 눌렀을 때 주소창의 주소가 바뀌는지 봅니다. 그대로라면 묶음별 주소가 없는 것입니다.
  2. 빌더 설정에서 '무한 스크롤' 대신 '페이지 번호(1 · 2 · 3)' 방식이 있는지 찾습니다. 소상공인 홈페이지는 이쪽이 관리하기 쉽습니다(일반 요령).
  3. 페이지 번호 방식이면 2쪽 · 3쪽 주소를 새 창에 직접 붙여 넣어, 그 묶음 내용이 바로 열리는지 확인합니다.
  4. 주소에 오늘 · 어제 · 최신처럼 날마다 뜻이 바뀌는 말이 들어 있지 않은지 봅니다.
  5. 목록 첫 묶음에 없는 중요한 사례 · 메뉴는 첫 화면이나 메뉴에서 상세 페이지로 바로 링크를 걸어 둡니다.
무한 스크롤을 유지하고 싶다면 제작자에게 '스크롤로 불러올 때 주소창도 ?page=2, ?page=3 으로 바뀌게, 그리고 그 주소로 직접 들어와도 같은 묶음이 열리게 해 달라'고 요청하면 뜻이 정확히 전달됩니다.

5구글이 내용을 다 봤는지 어떻게 확인하나요?

Google 검색 센터는 Search Console의 URL 검사 도구로 모든 콘텐츠가 로드됐는지 확인하라고 안내합니다. URL 검사에 주소를 넣고 색인을 요청하는 기본 순서는 Search Console URL 검사로 색인 요청하기 글에 있으니, 여기서는 지연 로드 확인에 필요한 부분만 적습니다(화면 이름은 바뀔 수 있습니다).

  1. 점검할 메뉴 · 시공사례 · 후기 페이지 주소를 URL 검사 창에 넣습니다.
  2. '실제 URL 테스트'를 눌러 지금 상태를 구글이 다시 읽게 합니다.
  3. '테스트한 페이지 보기'에서 HTML(구글이 렌더링한 결과)을 엽니다.
  4. '더보기' 뒤에 있던 메뉴 이름이나 사례 제목 하나를 골라, 그 글자가 HTML 안에 있는지 찾습니다.
  5. 스크린샷에서 첫 화면 대표 사진이 빈칸 없이 보이는지 확인합니다.
  6. 찾는 글자가 없으면 3 · 4번 표와 순서대로 고친 뒤, 다시 실제 URL 테스트를 합니다.

4번에서 첫 묶음의 글자만 있고 뒤쪽 묶음의 글자가 없다면, 그 내용은 지금 구조로는 구글에 전달되지 않는 것입니다. 이때는 페이지 번호 주소를 만들거나, 중요한 항목을 첫 묶음 · 상세 페이지 링크로 옮깁니다.

6고치기 전에 무엇부터 정하면 되나요?

모든 페이지를 한꺼번에 손볼 필요는 없습니다. 손님이 실제로 검색해서 들어올 페이지 두세 개만 먼저 봅니다(일반 요령).

  • 검색으로 들어오길 바라는 페이지 고르기: 메뉴, 시공사례, 오시는 길
  • 그 페이지에서 버튼 · 스크롤 뒤에 숨은 글자와 링크가 있는지 표시하기
  • 사진만 늦게 부르고 글자 · 링크는 처음부터 나오게 바꾸기
  • 긴 목록은 페이지 번호 주소로 나누기
  • URL 검사 실제 URL 테스트로 다시 확인하기

우리 홈페이지가 구글이 읽기 좋은 구조인지 한 번에 보고 싶다면 무료 SEO 점검에 주소를 넣어 보세요. 빌더 설정으로 해결이 안 되는 구조라면 제작 문의로 남겨 주시면 됩니다. 큰길브리지는 홈페이지 제작과 검색 노출 정리를 전국 비대면으로 진행합니다.

자주 묻는 질문

'더보기' 버튼 뒤의 내용도 구글 검색에 나오나요?

나오지 않을 수 있습니다. Google 검색 센터는 구글 검색이 페이지와 상호작용하지 않는다고 안내합니다. 버튼을 누르거나 스크롤해야만 나오는 내용은 구글이 보지 못할 수 있으니, 중요한 글자와 링크는 처음부터 나오게 하는 것이 안전합니다.

사진에 지연 로드를 걸면 검색에 불리한가요?

화면 아래쪽 사진을 늦게 불러오는 것은 속도에 도움이 됩니다. 다만 Google 검색 센터는 페이지를 열자마자 보일 가능성이 높은 콘텐츠에는 지연 로드를 넣지 말라고 안내합니다. 첫 화면 대표 사진은 처음부터 불러오세요.

무한 스크롤을 쓰면 안 되나요?

쓸 수는 있습니다. 대신 Google 검색 센터 안내처럼 묶음마다 ?page=2 같은 고유하고 지속적인 주소를 주고, 그 주소로 직접 들어와도 같은 묶음이 열리게 해야 합니다. ?date=yesterday 같은 상대적인 주소는 피합니다.

고친 뒤 제대로 됐는지는 어떻게 아나요?

Search Console URL 검사에서 실제 URL 테스트를 하고, 렌더링된 HTML 안에 '더보기' 뒤에 있던 메뉴 이름이나 사례 제목이 들어 있는지 찾아보면 됩니다.
