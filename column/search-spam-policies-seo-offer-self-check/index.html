2026-11-28 · 큰길브리지 · 읽는 시간 약 7분
검색 스팸 정책키워드 스터핑숨겨진 텍스트클로킹

'검색에 잘 나오게 해 드린다'는 제안 가운데 지역명 키워드 도배, 흰 글씨로 숨긴 글, 검색엔진에만 다른 화면 보여 주기, 몰래 다른 페이지로 보내기, 링크 사고팔기는 Google 검색 스팸 정책에 정면으로 걸리는 방법입니다. Google 검색 센터는 정책을 위반한 사이트가 검색 결과에서 순위가 낮아지거나 아예 나타나지 않을 수 있다고 안내합니다. 잠깐 효과가 있어 보여도 가게 홈페이지 전체를 걸고 하는 도박이라, 계약 전에 제안 문구를 한 줄씩 대조하고 이미 들어가 있는 것은 걷어 내는 편이 안전합니다.

핵심만 먼저
  • Google 검색 스팸 정책에는 클로킹, 도어웨이 악용, 숨겨진 텍스트 · 링크 악용, 키워드 스터핑, 링크 스팸, 대량 생성 콘텐츠 악용, 사기성 리디렉션 등이 들어 있습니다.

  • 같은 지역명 · 업종명을 부자연스럽게 반복하는 것은 키워드 스터핑, 배경색과 같은 글씨로 숨기는 것은 숨겨진 텍스트 악용입니다.
  • 손님과 검색엔진에 서로 다른 화면을 보여 주는 것은 클로킹, 누른 사람을 몰래 다른 곳으로 보내는 것은 사기성 리디렉션입니다.

1왜 '검색 잘 나오게 해 드린다'는 제안을 조심해야 하나요?

구글은 검색 순위를 속이려는 방법들을 모아 스팸 정책으로 공개해 두었습니다. Google 검색 센터 안내의 요지는, 이 정책을 위반한 사이트는 검색 결과에서 순위가 낮아지거나 아예 나타나지 않을 수 있다는 것입니다.

문제는 이런 방법이 영업 문구로 바뀌면 그럴듯하게 들린다는 점입니다. '지역 키워드를 촘촘히 깔아 드립니다', '검색엔진 전용 페이지를 따로 만들어 드립니다', '백링크 수백 개를 넣어 드립니다' 같은 말은 겉으로는 관리 서비스처럼 보입니다. 하지만 벌점을 받는 것은 업체가 아니라 사장님 홈페이지입니다. 계약이 끝나도 남은 흔적은 사장님이 치워야 합니다.

정책에 들어 있는 항목은 클로킹, 도어웨이 악용, 숨겨진 텍스트 · 링크 악용, 키워드 스터핑, 링크 스팸, 대량 생성 콘텐츠 악용, 사기성 리디렉션 등입니다. 아래에서는 소상공인 홈페이지에 실제로 자주 제안되는 다섯 가지를 골라 봅니다.

2어떤 제안 문구가 어떤 정책에 걸리나요?

왼쪽은 영업 때 흔히 듣는 말(일반 요령으로 정리한 예), 가운데는 Google 검색 스팸 정책의 해당 항목, 오른쪽은 같은 목적을 정상적으로 이루는 대안입니다.

업체 제안 문구해당 정책대안
"페이지 아래에 지역명 · 업종명을 가득 넣어 드려요"키워드 스터핑서비스 지역은 오시는 길 · 안내 문장에 자연스럽게 한 번씩
"손님 눈에는 안 보이게 키워드를 깔아 드려요"숨겨진 텍스트 · 링크 악용손님이 읽어도 쓸모 있는 설명 문단으로 쓰기
"검색엔진용 페이지를 따로 보여 줘요"클로킹손님과 검색엔진이 같은 화면을 보게 하기
"검색으로 들어오면 자동으로 예약 페이지로 넘겨요"사기성 리디렉션눌렀던 페이지에 예약 버튼을 눈에 띄게 두기
"동네별 페이지를 수십 개 찍어 드려요"도어웨이 악용 · 대량 생성 콘텐츠 악용실제로 다른 내용이 있는 지역만 따로 페이지 만들기
"백링크 수백 개 넣어 드려요"링크 스팸거래처 · 협회 · 지역 소개처럼 실제 관계가 있는 곳의 링크
표의 제안 문구는 이해를 돕기 위한 예시이며 특정 업체의 말이 아닙니다. 같은 뜻을 다른 말로 하는 경우가 많으니, 문구보다 실제로 무엇을 바꾸는지를 물어보세요.

3지역명을 여러 번 넣으면 왜 안 되나요?

Google 검색 센터는 키워드 스터핑을 검색 순위를 조작할 목적으로 페이지를 키워드나 숫자로 채우는 것이라고 설명합니다. 같은 단어나 구문을 부자연스러울 만큼 반복하는 것이 대표적인 예입니다. 페이지 맨 아래에 '○○동 미용실 ○○동 헤어샵 ○○동 펌 잘하는 곳 ○○동 미용실 추천'처럼 지역명과 업종명을 줄줄이 붙이는 방식이 여기에 해당합니다.

제목도 같습니다. 제목에 같은 단어를 반복하면 구글이 아예 다른 글자로 바꿔 보여 줄 수 있습니다. 이 내용은 검색 결과 제목이 내가 정한 제목과 다를 때 글에 자세히 정리했으니 여기서는 반복하지 않겠습니다.

서비스 지역을 알리고 싶다면 '○○동 ○○로 1층, ○○역에서 걸어서 오실 수 있습니다'처럼 손님에게 실제로 필요한 문장 안에 넣는 것이 가장 자연스럽습니다(일반 요령). 지역명은 손님이 읽었을 때 어색하지 않은 만큼만 씁니다.

4흰 글씨, 다른 화면, 몰래 이동은 어떻게 다른가요?

셋 다 '손님이 보는 것과 검색엔진이 보는 것이 다르다'는 점이 같습니다. Google 검색 센터 안내의 요지를 사장님 말로 풀면 이렇습니다.

  • 숨겨진 텍스트 · 링크 악용: 오직 검색 순위를 조작하려고 사용자에게 보이지 않게 글이나 링크를 두는 것입니다. 배경과 같은 색 글씨, 글자 크기나 불투명도를 0으로 만든 글, 이미지 뒤에 숨긴 글이 예입니다. 접었다 펼치는 메뉴나 탭처럼 손님이 눌러서 볼 수 있는 내용은 여기에 해당하지 않습니다.
  • 클로킹: 사용자와 검색엔진에 서로 다른 콘텐츠를 보여 주는 것입니다. 검색엔진에는 글이 빽빽한 페이지를, 손님에게는 사진 한 장만 보여 주는 식입니다.
  • 사기성 리디렉션: 검색 결과에서 누른 페이지가 아니라, 손님이 예상하지 못한 다른 페이지로 몰래 보내는 것입니다. 주소를 옮기면서 옛 주소를 새 주소로 잇는 정상적인 이동과는 다릅니다.

광고 문구를 두 가지로 나눠 시험하는 A/B 테스트가 클로킹이 되지 않으려면 어떻게 해야 하는지는 랜딩페이지 A/B 테스트와 구글 검색 글에 따로 정리했습니다. 테스트 자체는 문제가 아니고, 검색엔진만 따로 대접하는 것이 문제입니다.

5링크를 사고파는 것은 왜 문제인가요?

링크 스팸은 검색 순위를 올리려고 링크를 만들거나 사고파는 것을 말합니다. 돈을 주고 아무 관계 없는 사이트에 우리 주소를 잔뜩 걸게 하거나, 서로 링크를 걸어 주기만 하는 모임에 들어가는 것, 프로그램으로 게시판 · 댓글에 주소를 뿌리는 것이 흔한 예입니다.

그렇다고 링크가 모두 나쁜 것은 아닙니다. 거래처 홈페이지의 협력사 소개, 지역 상인회 회원 목록, 언론 기사처럼 실제 관계가 있어서 생긴 링크는 자연스럽습니다. 체험단이나 협찬 글처럼 대가가 있는 링크라면 그 사실을 표시하는 것이 정석입니다. 네이버 블로그와 홈페이지를 잇는 경우는 네이버 블로그 홈페이지 링크와 협찬 표시 글을 참고하세요.

6내 홈페이지는 괜찮은지 어떻게 직접 확인하나요?

업체가 무엇을 넣었는지 모르겠다면 아래 순서로 직접 볼 수 있습니다(일반 요령). 프로그램을 몰라도 됩니다.

  1. 휴대폰과 컴퓨터에서 첫 화면 · 메뉴 · 오시는 길 페이지를 열고, 화면 맨 아래까지 내려 지역명 · 업종명이 줄줄이 붙어 있지 않은지 봅니다.
  2. 컴퓨터에서 페이지를 연 뒤 Ctrl+A(맥은 Command+A)로 전체 선택합니다. 빈칸처럼 보이던 곳에 파랗게 선택되는 글자가 나타나면 숨겨진 텍스트일 수 있습니다.
  3. 페이지에서 마우스 오른쪽 버튼 → '페이지 소스 보기'를 누르고 Ctrl+F 로 가게 지역명을 찾아봅니다. 화면에는 없는데 소스에만 여러 번 나오면 업체에 이유를 묻습니다.
  4. 구글에서 'site:내주소' 로 검색해 결과를 하나씩 눌러 봅니다. 누른 페이지와 다른 곳으로 넘어가거나, 검색 결과 설명과 전혀 다른 화면이 나오면 리디렉션 · 클로킹을 의심합니다.
  5. Search Console 이 연결되어 있다면 '보안 및 직접 조치' 메뉴에서 수동 조치 기록이 있는지 봅니다. 없다는 안내가 나오면 사람 검토로 받은 조치는 없는 것입니다.
  6. 문제를 찾으면 업체에 무엇을 넣었는지 목록을 받고, 숨긴 글 · 도배된 키워드 · 이상한 이동 설정을 지운 뒤 다시 1번부터 확인합니다.
검색에 안 나오는 이유가 스팸 문제가 아니라 단순히 색인이 안 된 것일 수도 있습니다. 그런 경우는 Search Console 페이지 색인이 안 되는 이유 글부터 보세요.

7계약 전에 업체에 무엇을 물어보면 되나요?

정상적인 검색 노출 관리는 무엇을 했는지 설명할 수 있는 일입니다. 아래 질문에 시원하게 답하지 못하면 한 번 더 생각해 보세요(일반 요령).

  • 홈페이지에 정확히 어떤 글 · 설정을 넣거나 바꾸나요? 목록으로 받을 수 있나요?
  • 손님이 보는 화면과 검색엔진이 보는 화면이 같은가요?
  • 링크는 어디에서, 어떤 관계로 생기나요?
  • 계약이 끝나면 넣은 것을 어떻게 정리하나요?
  • '순위 보장' 같은 말 대신 무엇을 기준으로 결과를 확인하나요?

결국 오래가는 방법은 손님에게 쓸모 있는 페이지를 만드는 것입니다. 메뉴 · 영업시간 · 오시는 길 · 예약 방법처럼 손님이 찾는 내용을 정확히 적고, 페이지마다 제목과 설명을 정리하는 쪽이 정책 걱정 없이 쌓입니다. 지금 홈페이지 상태를 한 번에 보고 싶다면 무료 SEO 점검에 주소를 넣어 보세요. 큰길브리지는 홈페이지 제작과 검색 노출 정리를 전국 비대면으로 진행합니다.

자주 묻는 질문

지역명을 페이지에 몇 번까지 넣어도 되나요?

정해진 숫자는 없습니다. Google 검색 센터는 같은 단어나 구문을 부자연스러울 만큼 반복하는 것을 키워드 스터핑의 예로 듭니다. 손님이 소리 내어 읽었을 때 어색하지 않은 문장 안에서만 쓰는 것이 기준입니다.

접었다 펼치는 메뉴나 탭 안의 글도 숨겨진 텍스트인가요?

손님이 눌러서 볼 수 있도록 만든 내용은 숨겨진 텍스트 악용이 아닙니다. 문제가 되는 것은 오직 검색 순위를 조작하려고 손님이 볼 수 없게 둔 글, 예를 들어 배경색과 같은 글씨나 크기 · 불투명도를 0으로 만든 글입니다.

스팸 정책을 어기면 어떻게 되나요?

Google 검색 센터는 정책을 위반한 사이트가 검색 결과에서 순위가 낮아지거나 아예 나타나지 않을 수 있다고 안내합니다. 홈페이지 일부가 아니라 사이트 전체가 영향을 받을 수도 있으니 미리 걷어 내는 것이 좋습니다.

예전 업체가 넣은 것을 지우면 바로 회복되나요?

지운 내용이 반영되려면 구글이 페이지를 다시 읽어야 해서 시간이 걸립니다. Search Console 에 수동 조치 기록이 있다면 문제를 고친 뒤 그 화면에서 재검토를 요청할 수 있습니다.
