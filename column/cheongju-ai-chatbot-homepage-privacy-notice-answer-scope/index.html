1챗봇을 붙이면 가게가 새로 챙길 일이 생기나요?

개인정보보호위원회가 2025년 8월 공개한 '생성형 인공지능(AI) 개발 · 활용을 위한 개인정보 처리 안내서'는 개발 방식을 서비스형 LLM 활용(예: ChatGPT API 연계), 기성 LLM 활용, 자체개발로 나누어 다룹니다. 가게 홈페이지에 외부 AI를 연결한 챗봇은 대개 첫째 유형에 가깝습니다. 직접 AI를 만들지 않았더라도 그 대화가 오가는 창구는 가게 홈페이지라는 점을 기억해 둡니다.
