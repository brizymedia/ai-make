홈페이지 404 페이지없는 페이지 안내 화면404 410 차이301 리디렉션

연말에 지난 이벤트 페이지나 없어진 메뉴 페이지를 지울 때는 페이지마다 301 · 404 · 410 중 하나를 골라 처리하고, 손님이 길을 잃지 않도록 홈페이지 404 페이지(없는 페이지 안내 화면)를 함께 준비합니다. Google Search Central의 크롤링 오류 안내 요지는, 페이지를 옮겼으면 301 리디렉션을, 삭제했고 비슷한 대체 페이지가 없으면 404 또는 410을 돌려주라는 것입니다. 안내 화면을 꾸며도 서버가 200(성공)을 돌려주면 soft 404가 되니, 화면과 상태 코드를 따로 확인해야 합니다.

핵심만 먼저
  • 주소만 바뀌었거나 내용을 이어받는 새 페이지가 있으면 301 리디렉션으로 옮깁니다(Google 안내 요지).
  • 삭제했고 비슷한 대체 페이지가 없으면 404(not found) 또는 410(gone)을 돌려줍니다(Google 안내 요지).
  • '페이지가 없습니다'라고 보여 주면서 200(성공)을 돌려주면 soft 404이고, Google은 이를 나쁜 사용자 경험으로 봅니다.
  • 맞춤 404 페이지는 손님을 위한 화면이고, 서버는 404 상태 코드를 돌려줘 그 화면이 색인되지 않게 해야 합니다(Google 안내 요지).
  • 안내 화면에는 홈 · 문의 · 검색(또는 주요 메뉴) 링크를 넣고, 지운 페이지 목록을 표로 남겨 두면 다음 정리가 쉽습니다(일반 요령).

1연말에 지운 페이지, 그냥 삭제하면 안 되나요?

301페이지를 옮겼을 때 — 영구 이동(Google 안내)
404삭제했고 대체 페이지가 없을 때 — not found(Google 안내)
410삭제했고 대체 페이지가 없을 때 — gone(Google 안내)

12월이 되면 정리할 페이지가 쌓입니다. 끝난 추석 · 할로윈 이벤트 안내, 메뉴판을 바꾸면서 빠진 계절 메뉴 소개, 마감된 모집 공고 같은 것들입니다. 페이지를 지우는 것 자체는 문제가 아닙니다. 다만 그 주소는 검색 결과, 블로그 글, 카카오톡 공유 링크, 인쇄물 QR에 남아 있어서 누군가는 계속 누릅니다.

그래서 지울 때 정할 것은 하나입니다. 이 주소로 들어온 사람을 어디로 보낼지입니다. 갈 곳이 있으면 옮겨 주고(301), 갈 곳이 없으면 '없다'고 정직하게 알려 줍니다(404 · 410). Google Search Central의 크롤링 오류 문제 해결 문서(영문 원문을 우리말로 풀어 옮긴 요지)도 이 두 갈래로 안내합니다.

2어떤 페이지는 301, 어떤 페이지는 404 · 410인가요?

기준은 '내용을 이어받는 페이지가 있느냐'입니다. 아래 표는 가게 홈페이지에서 연말에 자주 나오는 경우를 정리한 것입니다. 처리 방법 칸은 Google 안내 요지를, 예시 칸은 일반 요령을 따랐습니다.

지우려는 페이지이어받을 페이지처리 방법
여름 메뉴 소개(같은 메뉴가 사계절 메뉴판으로 옮겨감)있음 — 새 메뉴판 페이지301 리디렉션
작년 송년 이벤트(올해 같은 이벤트를 새 주소로 다시 엶)있음 — 올해 이벤트 페이지301 리디렉션
주소 체계를 바꾼 서비스 소개(/menu1 → /menu/coffee)있음 — 같은 내용의 새 주소301 리디렉션
단종된 메뉴, 비슷한 메뉴 없음없음404 또는 410
끝난 1회성 할로윈 이벤트없음404 또는 410
마감된 아르바이트 모집 공고없음404 또는 410
지운 페이지를 전부 홈 화면으로 보내는 경우가 흔합니다. 이어받는 내용이 없는데 홈으로 보내면 손님은 찾던 것이 왜 없는지 모른 채 첫 화면에 떨어집니다. 내용이 이어지는 페이지가 있을 때만 옮기고, 없으면 404 · 410으로 알리는 편이 정직합니다(일반 요령).

404와 410은 둘 다 '없음'을 알리는 상태 코드입니다. 404는 '찾을 수 없음', 410은 '일부러 없앴음'에 가까운 뜻입니다. Google 안내는 대체 페이지가 없을 때 둘 중 하나를 쓰라고 하므로, 사장님 홈페이지에서는 설정하기 쉬운 쪽을 고르면 됩니다. 대부분의 호스팅 · 빌더는 404를 기본으로 돌려줍니다(일반 요령).

3지우기 전에 무엇부터 정리하나요?

  1. 지울 페이지 주소를 모읍니다. 이벤트 · 메뉴 · 공지 게시판에서 끝난 페이지 주소를 하나씩 복사해 표에 적습니다(일반 요령).
  2. 주소마다 '이어받을 페이지'를 적습니다. 있으면 새 주소를, 없으면 '없음'이라고 씁니다. 이 칸이 301과 404 · 410을 가릅니다.
  3. 바깥에 퍼진 곳을 확인합니다. 네이버 플레이스 소식, 인스타그램 프로필 링크, 전단 QR에 그 주소가 들어가 있는지 봅니다. 바깥 링크 정리는 주소 변경 뒤 바깥 링크 체크표에 정리해 두었습니다.
  4. 301 대상부터 설정합니다. 옛 주소에서 새 주소로 바로 가는지 하나씩 눌러 봅니다. 리디렉션 설정 순서는 리뉴얼 주소 변경과 301 리디렉션 글을 참고하세요.
  5. 나머지 페이지를 지웁니다. 지운 주소를 눌렀을 때 맞춤 안내 화면이 뜨는지, 상태 코드가 404인지 4번 방법으로 확인합니다.
일반 요령 — 끝난 행사라도 사진 · 후기 정리 페이지로 남길 가치가 있다면 지우지 않고 '종료된 행사'라고 화면에 적어 두는 방법도 있습니다. 행사 페이지를 남겨 둘 때의 표시 방법은 이벤트 구조화 데이터와 취소 표시 글에 있습니다.

4soft 404는 왜 생기고 어떻게 피하나요?

Google 안내 요지에 따르면 soft 404는 사용자에게는 페이지가 없다고 알리면서 서버는 200(성공) 상태 코드를 돌려주는 경우이고, 나쁜 사용자 경험입니다. 화면에는 '찾으시는 페이지가 없습니다'가 보이는데 검색엔진 입장에서는 '정상 페이지'로 들어오니, 내용 없는 페이지가 색인 후보로 남게 됩니다.

가게 홈페이지에서 soft 404가 생기는 흔한 경우는 이렇습니다(일반 요령).

  • 빌더에서 페이지 내용만 비운 경우 — 글은 지웠는데 페이지 자체는 남아 빈 화면이 200으로 열립니다.
  • '이벤트가 종료되었습니다' 한 줄만 남긴 경우 — 다른 내용 없이 안내 한 줄만 있고 상태는 200입니다.
  • 없는 주소를 모두 안내 페이지 주소(예: /notfound.html)로 옮긴 경우 — 안내 페이지 자체가 200으로 열리면 결국 같은 문제입니다.
  • 게시판 글을 지운 뒤 '삭제된 글입니다'를 보여 주는 경우 — 게시판 프로그램에 따라 200을 돌려주기도 합니다.

확인 방법은 간단합니다. Google Search Console의 URL 검사에 지운 주소를 넣어 보거나, 브라우저 개발자 도구(F12)의 네트워크 탭에서 그 주소를 새로 고쳐 상태 코드 칸을 봅니다. 404 또는 410이 보이면 맞고, 200이 보이면 설정을 고쳐야 합니다(일반 요령).

5없는 페이지 안내 화면에는 무엇을 넣나요?

Google 안내 요지는 맞춤 404 페이지가 사용자를 위한 화면이라는 것입니다. 그러니 화면은 손님 눈높이로 만들고, 상태 코드는 서버에서 404로 따로 지킵니다. 안내 화면에 넣을 것은 아래 정도면 충분합니다(일반 요령).

넣을 것예시 문구이유
짧은 안내찾으시는 페이지가 없거나 행사가 끝났습니다왜 이 화면이 떴는지 바로 알게 함
홈 링크첫 화면으로 가기가장 먼저 누르는 출구
문의 링크전화 · 카카오톡 · 문의하기찾던 것을 직접 물어볼 수 있게 함
검색 또는 주요 메뉴메뉴 · 이벤트 · 오시는 길비슷한 내용을 스스로 찾게 함
사이트와 같은 디자인로고 · 상단 메뉴 그대로다른 사이트로 넘어간 것 같은 불안을 줄임

정적 홈페이지라면 사이트 맨 위 폴더에 404.html 파일 하나를 두는 방식이 흔하고, 호스팅에 따라 설정 화면에서 '오류 페이지'를 지정하기도 합니다. 어느 쪽이든 안내 화면을 띄운 상태에서 상태 코드가 404로 나오는지 4번 방법으로 다시 봅니다. 화면 구성과 빌더별 설정은 404 페이지 만들기와 soft 404 글에 더 자세히 있습니다.

6정리가 끝난 뒤에는 무엇을 확인하나요?

  1. 정리표를 저장합니다. 지운 주소 · 처리 방법(301 · 404 · 410) · 옮긴 주소 · 날짜를 남겨 두면 내년 이맘때 같은 일을 반복하지 않습니다(일반 요령).
  2. 사이트맵에서 지운 주소를 뺍니다. 사이트맵에 404 주소가 남아 있으면 검색엔진에 '있는 페이지'라고 계속 알리는 셈입니다(일반 요령).
  3. 메뉴 · 본문 링크를 고칩니다. 홈페이지 안에서 지운 페이지로 가는 링크가 남아 있지 않은지 확인합니다.
  4. 몇 주 뒤 Search Console을 봅니다. 페이지 색인 보고서에 soft 404로 잡힌 주소가 있으면 4번의 경우 중 어디에 해당하는지 찾아 고칩니다(일반 요령).

우리 홈페이지에서 지운 페이지가 제대로 404를 돌려주는지, soft 404로 남은 주소는 없는지 궁금하다면 무료 SEO 점검을 먼저 받아 보세요. 큰길브리지는 홈페이지 제작 · 관리를 전국 비대면으로 진행합니다. 없는 페이지 안내 화면과 리디렉션 정리를 함께 맡기고 싶다면 제작 문의에 남겨 주세요.

자주 묻는 질문

끝난 이벤트 페이지는 301로 옮겨야 하나요, 404로 둬야 하나요?

내용을 이어받는 페이지(예: 올해 같은 이벤트 페이지)가 있으면 301 리디렉션으로 옮기고, 비슷한 대체 페이지가 없으면 404 또는 410을 돌려줍니다. Google 크롤링 오류 안내의 요지입니다.

404와 410은 무엇이 다른가요?

404는 '찾을 수 없음', 410은 '일부러 없앴음'에 가까운 뜻입니다. Google은 페이지를 삭제했고 대체 페이지가 없으면 둘 중 하나를 돌려주라고 안내하므로, 설정하기 쉬운 쪽을 쓰면 됩니다.

soft 404는 무엇인가요?

화면으로는 페이지가 없다고 알리면서 서버는 200(성공) 상태 코드를 돌려주는 경우입니다. Google은 이를 나쁜 사용자 경험으로 봅니다. 안내 화면을 띄울 때도 상태 코드는 404여야 합니다.

지운 페이지를 모두 홈 화면으로 보내면 안 되나요?

이어받는 내용이 없는데 홈으로 보내면 손님은 찾던 것이 왜 없는지 알 수 없습니다. 내용이 이어지는 페이지가 있을 때만 301로 옮기고, 없으면 404 · 410과 안내 화면으로 알리는 편이 낫습니다(일반 요령).

홈페이지 404 페이지에는 무엇을 넣으면 되나요?

짧은 안내 문구, 홈 링크, 문의(전화 · 카카오톡) 링크, 검색 또는 주요 메뉴 링크를 넣고 사이트와 같은 디자인으로 만듭니다. 화면은 손님을 위한 것이고 서버는 404 상태 코드를 돌려줘야 합니다.
