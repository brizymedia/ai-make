안산 홈페이지 보안 경고, '안전하지 않음'이 뜰 때 원인 가려내는 법

2026-10-07 · 큰길브리지 · 읽는 시간 약 7분
안산 홈페이지 보안 경고안전하지 않음 경고주의 요함 크롬SSL 인증서 만료

안산 홈페이지 보안 경고는 대부분 세 갈래 중 하나입니다. 홈페이지가 HTTPS(암호화 연결)를 쓰지 않거나, HTTPS용 인증서가 만료 · 불일치 상태이거나, https 페이지 안에 http로 불러오는 사진 · 파일이 섞여 있는 경우입니다. 어느 쪽인지는 경고 화면의 문구와 오류 코드로 가려낼 수 있고, 고치는 사람도 갈래마다 다릅니다.

핵심만 먼저
  • Chrome 고객센터는 '안전하지 않음' 표시를 '이 사이트를 통해 보내거나 받는 정보를 다른 사람이 보고 변경할 수도 있다'는 뜻으로 설명합니다.
  • 예전에 많이 보던 '주의 요함'은 Chrome 68(2018년)부터 HTTP 사이트에 붙던 표시입니다. 지금 고객센터 문서는 '안전하지 않음'이라고 적습니다.
  • 구글은 2026년 10월 Chrome 154부터 '항상 보안 연결 사용'(공개 사이트)을 모든 사용자에게 기본으로 켜겠다고 2025년 10월 발표했습니다. HTTPS가 없는 홈페이지는 들어가기 전에 경고 화면이 뜰 수 있습니다.
  • https 페이지가 http로 사진 · 스크립트를 불러오면 '혼합 콘텐츠'가 되고, 브라우저가 이를 막거나 주소창에 안전하지 않다고 표시할 수 있습니다(web.dev).

1주소창 경고는 몇 가지이고, 각각 무슨 뜻인가요?

Chrome 고객센터는 주소 왼쪽의 보안 상태 기호를 세 가지로 나눕니다. 손님 휴대폰에 무엇이 보이는지에 따라 원인 후보가 달라집니다.

보이는 표시Chrome 고객센터 설명흔한 원인(일반적인 경우)주로 고치는 곳
기본 기호(안전함)보내거나 받는 정보가 사용자와 사이트 간에 비공개HTTPS 정상할 일 없음
정보 또는 '안전하지 않음'비공개 연결을 사용하지 않아 다른 사람이 보고 변경할 수도 있음HTTPS 미적용, 또는 https 페이지 안의 http 파일호스팅 설정 · 홈페이지 코드
빨간 '안전하지 않음' 또는 '위험'연결에 개인 정보 보호 문제가 있거나, 세이프 브라우징에서 신고된 사이트인증서 만료 · 주소 불일치, 또는 악성코드 신고인증서 갱신 · 보안 점검

'주의 요함'이라는 말로 기억하는 분도 많습니다. 구글 코리아 개발자 블로그는 2018년 7월 글에서 Chrome 68부터 모든 HTTP 사이트를 '주의 요함'으로 표시한다고 안내했습니다. 이름은 바뀌었어도 뜻은 같습니다. 이 홈페이지는 암호화 연결을 쓰지 않는다는 신호입니다.

전체 화면이 빨간색으로 바뀌는 경고는 성격이 다릅니다. Chrome 고객센터는 이 경우 세이프 브라우징에서 안전하지 않다고 신고한 사이트라고 설명합니다. 인증서보다 홈페이지 파일이 오염됐는지부터 점검해야 합니다.

22026년 10월부터 왜 경고를 더 자주 보게 되나요?

Chrome 154'항상 보안 연결 사용' 기본 적용 예정 버전(Google, 2025.10.28 발표)
2026년 10월공개 사이트 대상 기본 적용 예정 시기(같은 발표)

Chrome에는 '항상 보안 연결 사용'이라는 설정이 있습니다. Chrome 고객센터 설명대로 이 설정이 켜져 있으면 Chrome은 주소를 HTTPS로 바꿔 접속해 보고, HTTPS를 지원하지 않는 사이트는 들어가기 전에 경고를 보여 줍니다.

구글은 2025년 10월 28일 글에서 이 설정을 2026년 10월 Chrome 154 출시와 함께 공개 사이트에 대해 기본으로 켜겠다고 밝혔습니다. 같은 글에 따르면 자주 방문하는 사이트는 반복해서 경고하지 않도록 설계했습니다. 하지만 처음 들어오는 손님, 곧 검색이나 명함 QR로 처음 찾아온 사람은 경고 화면을 먼저 보게 됩니다.

실제 적용 시점과 범위는 Chrome 업데이트 상황에 따라 달라질 수 있습니다. 내 홈페이지가 아직 http:// 로만 열린다면 이번 기회에 HTTPS부터 켜 두는 편이 안전합니다.

3인증서 만료와 주소 불일치는 어떻게 구별하나요?

'연결이 비공개로 설정되어 있지 않습니다' 화면 아래에는 작은 글씨로 오류 코드가 붙습니다. 코드 이름만 봐도 갈래를 좁힐 수 있습니다.

  • NET::ERR_CERT_DATE_INVALID — Chrome 고객센터는 컴퓨터나 휴대기기의 날짜 · 시간이 잘못 설정됐을 때 이 오류가 보일 수 있다고 안내합니다. 그러니 먼저 내 기기 시계를 확인합니다. 시계가 맞는데 여러 기기에서 똑같이 뜬다면, 일반적으로는 홈페이지 인증서의 유효기간이 지난 경우입니다.
  • ERR_CERT_COMMON_NAME_INVALID — 인증서에 적힌 주소와 접속한 주소가 다를 때 흔히 보입니다(일반적인 경우). 예를 들어 인증서가 www 없는 주소만 담고 있는데 손님이 www를 붙여 들어온 경우입니다.
  • NET::ERR_CERT_AUTHORITY_INVALID — 일반적으로는 브라우저가 믿는 발급 기관의 인증서가 아닐 때 보입니다. 회사 컴퓨터에서만 뜬다면 Chrome 고객센터 안내처럼 회사 프록시 설정 문제일 수 있습니다.

인증서는 정해진 기간마다 새로 받아야 합니다(일반 원리). 호스팅 업체가 자동으로 갱신해 주는 곳도 있고, 직접 갱신해야 하는 곳도 있습니다. 내 호스팅이 어느 쪽인지, 만료일이 언제인지 계약 화면에서 한 번 확인해 두십시오.

도메인 · DNS · HTTPS가 처음부터 어떻게 이어지는지는 도메인 연결 정리 글에 따로 정리해 두었습니다.

4자물쇠가 있는데도 '안전하지 않음'이 뜨면 무엇을 보나요?

주소는 https:// 로 시작하는데 경고가 남아 있다면 혼합 콘텐츠를 의심합니다. web.dev는 첫 HTML은 HTTPS로 불러왔지만 사진 · 동영상 · 스타일시트 · 스크립트 같은 다른 파일을 HTTP로 불러오는 페이지를 혼합 콘텐츠라고 정의합니다.

구분(web.dev)예브라우저 동작
수동 혼합 콘텐츠사진, 동영상, 소리Chrome은 HTTPS 버전이 있으면 자동으로 바꿔 불러오고, 없으면 막을 수 있음. 주소창에 안전하지 않다고 표시하기도 함
능동 혼합 콘텐츠스크립트, 스타일시트, iframe대부분의 브라우저가 기본으로 차단 → 디자인이 깨지거나 버튼이 작동하지 않을 수 있음

오래된 홈페이지에서 흔한 경우는 이렇습니다(일반적인 경우). 몇 년 전 게시판에 올린 사진 주소가 http:// 로 저장돼 있거나, 예전에 붙인 지도 · 동영상 · 상담 위젯 코드가 http 주소를 쓰는 경우입니다.

  1. 경고가 뜨는 페이지를 PC Chrome으로 열고 F12를 눌러 '콘솔(Console)' 탭을 엽니다. web.dev 설명대로 혼합 콘텐츠는 이곳에 오류 · 경고로 나타납니다.
  2. 메시지에 나온 http:// 주소를 복사해 https:// 로 바꿔 브라우저에서 직접 열어 봅니다.
  3. https로도 열리면 홈페이지 코드 속 주소를 https로 고칩니다.
  4. https로 열리지 않으면 다른 안전한 곳에 올리거나, 직접 호스팅하거나, 빼는 방법 중에서 고릅니다(web.dev 안내).

5사장님이 10분 안에 해 볼 점검 순서는?

  1. 휴대폰 데이터로 내 홈페이지 주소를 http:// 를 붙여 직접 입력해 봅니다. https:// 로 넘어가는지 봅니다.
  2. www를 붙인 주소와 뺀 주소를 각각 열어 봅니다. 한쪽만 인증서 오류가 나면 주소 불일치 갈래입니다.
  3. 주소창 왼쪽 기호를 눌러 '연결이 안전함'인지 확인합니다.
  4. 메인 말고 오래된 게시글, 문의 페이지도 열어 봅니다. 혼합 콘텐츠는 일부 페이지에만 있는 경우가 많습니다(일반적인 경우).
  5. 결과를 캡처해 호스팅 업체나 제작 업체에 보냅니다. 오류 코드가 보이게 찍으면 원인 찾기가 빨라집니다.

6안산 공단 거래처를 상대하는 업체라면 왜 더 서둘러야 할까요?

안산시 누리집의 시 현황을 보면 안산은 상록구 · 단원구 2개 구, 25개 동으로 이루어져 있고, 반월 국가산업단지와 시화 국가산업단지가 있는 산업도시입니다. 공단 안 제조 · 납품 업체는 처음 거래하는 회사 담당자가 홈페이지를 열어 보고 견적을 넣는 일이 많습니다.

회사 컴퓨터는 보안 설정이 엄격한 경우가 많아, 경고가 뜨는 홈페이지는 담당자가 아예 들어가지 않거나 문의 폼을 쓰지 않고 닫을 수 있습니다(일반적인 경우). 견적 문의 폼이 있는 업체라면 폼 페이지만큼은 꼭 HTTPS로 열리게 해 두십시오.

큰길브리지는 안산 업체의 홈페이지 점검 · 제작도 전국 비대면으로 진행합니다. HTTPS 전환이나 새 홈페이지가 필요하면 제작 문의에 현재 주소와 경고 화면 캡처를 남겨 주세요.

자주 묻는 질문

'안전하지 않음'이 뜨면 해킹을 당한 건가요?

대부분은 아닙니다. 회색 '안전하지 않음'은 주로 HTTPS를 쓰지 않거나 http 파일이 섞였다는 뜻입니다. 다만 화면 전체가 빨갛게 바뀌는 경고는 Chrome 고객센터 설명대로 세이프 브라우징에서 신고된 경우일 수 있어, 홈페이지 파일 점검이 필요합니다.

우리 컴퓨터에서만 인증서 오류가 떠요.

먼저 기기 날짜 · 시간이 맞는지 봅니다. Chrome 고객센터는 시계가 잘못되면 NET::ERR_CERT_DATE_INVALID가 보일 수 있다고 안내합니다. 회사 컴퓨터라면 보안 프로그램이나 프록시 설정 때문일 수도 있습니다. 휴대폰 데이터로 열어 비교해 보십시오.

HTTPS로 바꾸면 검색 순위가 떨어지나요?

주소가 http에서 https로 바뀌는 것은 사이트 이전에 해당합니다. 301 리디렉션과 새 사이트맵 제출 같은 순서는 도메인 연결 정리 글에 구글 문서 기준으로 따로 적어 두었습니다.

안산에서는 방문 상담이 되나요?

안산은 큰길브리지의 직접 방문 지역이 아니어서 전국 비대면으로 진행합니다. 화면 캡처와 주소를 보내 주시면 원격으로 함께 확인합니다.
