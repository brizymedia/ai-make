색인 생성 안 됨 — Search Console 페이지 보고서, 사유별로 고칠 것과 둘 것

2026-11-25 · 큰길브리지 · 읽는 시간 약 7분
색인 생성 안 됨페이지 색인 생성 보고서크롤링됨 - 현재 색인이 생성되지 않음발견됨 - 현재 색인이 생성되지 않음

Search Console '페이지' 보고서에 색인 생성 안 됨 페이지가 수십 개 떠 있어도, 대부분은 고칠 필요가 없습니다. 리디렉션되는 옛 주소, 일부러 noindex 를 건 관리 페이지, 아무도 링크하지 않는 404 주소는 원래 색인에 오르지 않는 것이 맞습니다. 고칠 것은 손님이 찾아야 하는 페이지가 목록에 들어 있을 때뿐입니다. 고객센터도 페이지가 500개 미만인 사이트는 이 보고서를 쓰지 않아도 될 가능성이 높다고 안내합니다. 사유별로 무엇을 고치고 무엇을 그냥 두는지 정리했습니다.

핵심만 먼저
  • '색인이 생성되지 않음' 숫자가 크다고 사이트에 문제가 있다는 뜻은 아닙니다. 사유와 예시 주소를 보고 판단합니다.
  • 중요한 페이지가 'URL이 NOINDEX로 표시됨'에 있으면 noindex 설정을 지워야 합니다. 일부러 숨긴 페이지라면 그대로 둡니다.
  • '리디렉션이 포함된 페이지'는 옛 주소가 새 주소로 넘어가는 정상 상태라 대부분 그냥 둡니다.
  • 404 는 사이트 안 링크나 사이트맵에 걸려 있는 것만 고치는 것이 좋다고 고객센터가 안내합니다.
  • 고친 뒤 '수정 결과 확인'을 누르면 일반적으로 최대 2주 안에 결과가 나옵니다.

1'색인이 생성되지 않음'이 많으면 큰일인가요?

500개이보다 페이지가 적으면 이 보고서를 쓰지 않아도 될 가능성이 높음(고객센터)
2주수정 결과 확인에 일반적으로 걸리는 최대 기간(고객센터)
1,000개사유별로 보여 주는 예시 URL 최대 개수(고객센터)

아닙니다. 구글은 사이트의 모든 주소를 색인에 올리지 않습니다. 같은 페이지가 주소만 달리 여러 개 있거나, 다른 곳으로 넘어가는 주소, 일부러 숨긴 주소는 빠지는 것이 오히려 정상입니다. 그래서 보고서의 '색인이 생성되지 않음' 숫자가 '색인이 생성됨'보다 커도 놀랄 필요가 없습니다.

고객센터 안내에 따르면 페이지가 500개 미만인 사이트는 이 보고서를 쓰지 않아도 될 가능성이 높습니다. 식당 · 학원 · 병원 홈페이지처럼 페이지가 수십 개인 곳은 중요한 페이지 몇 개가 검색에 나오는지만 챙기면 됩니다. 한 페이지씩 확인하는 방법은 URL 검사로 색인 요청하기 글에 정리했습니다.

판단 기준은 하나입니다. 목록에 있는 주소가 '손님이 검색해서 들어와야 하는 페이지'인가? 아니면 그냥 둡니다. 맞으면 아래 사유별 표를 보고 고칩니다.

2페이지 보고서는 어디를 보면 되나요?

Search Console 왼쪽 메뉴의 페이지를 누르면 위쪽에 '색인이 생성됨'과 '색인이 생성되지 않음' 숫자가, 아래쪽에 '페이지 색인이 생성되지 않는 이유' 표가 나옵니다. 처음 보는 사장님은 아래 순서로 읽으면 됩니다(일반 요령).

  1. 아래쪽 사유 표에서 사유 이름과 페이지 수를 훑어봅니다. 숫자가 큰 사유부터가 아니라 이름부터 봅니다.
  2. 사유 한 줄을 눌러 예시 URL 목록을 엽니다. 사유별로 최대 1,000개까지 보여 줍니다.
  3. 목록에 첫 화면 · 메뉴 · 예약 · 오시는 길처럼 중요한 페이지가 있는지 찾습니다.
  4. 중요한 페이지가 없으면 그 사유는 닫고 다음 사유로 넘어갑니다.
  5. 중요한 페이지가 있으면 그 주소를 URL 검사에 넣어 자세한 이유를 확인한 뒤 3번 표대로 고칩니다.
이 보고서는 매일 바로 바뀌지 않습니다. 오늘 고친 내용이 다음 날 숫자에 바로 반영되지 않는다고 같은 일을 반복하지 마세요.

3사유별로 무엇을 고치고 무엇은 그냥 두나요?

자주 보이는 사유 다섯 가지입니다. 사유 설명은 고객센터 「페이지 색인 생성 보고서」 문장 그대로이고, '할 일'은 소상공인 홈페이지 기준의 일반 요령입니다.

사유고객센터 설명그냥 둬도 되는 경우고칠 때 할 일
크롤링됨 - 현재 색인이 생성되지 않음Google에서 페이지를 크롤링했지만 색인은 생성되지 않았습니다.태그 · 검색 결과 · 빈 게시판 페이지중요 페이지면 글자 내용 보강, 비슷한 페이지 합치기
발견됨 - 현재 색인이 생성되지 않음Google에서 페이지를 발견했지만 페이지가 아직 크롤링되지 않았습니다.새로 올린 지 얼마 안 된 페이지첫 화면 · 메뉴에서 링크 걸기, 사이트맵 확인
URL이 'NOINDEX'로 표시됨Google에서 페이지의 색인을 생성하려고 했지만 'NOINDEX' 명령어를 발견하여 색인을 생성하지 않았습니다.관리자 · 장바구니 · 감사 페이지처럼 일부러 숨긴 곳중요 페이지면 빌더의 '검색 노출 안 함' 설정 끄기
리디렉션이 포함된 페이지다른 페이지로 리디렉션되는 비표준 URL입니다. 따라서 이 URL의 색인은 생성되지 않습니다.http → https, 옛 주소 → 새 주소새 주소가 '색인이 생성됨'에 있는지만 확인
찾을 수 없음(404)이 페이지를 요청했을 때 404 오류가 반환되었습니다.오래전 지운 페이지, 외부에서 잘못 적은 주소사이트 안 링크 · 사이트맵에 걸린 것만 고치기

표에서 보듯 대부분의 사유는 '그냥 둬도 되는 경우'가 더 흔합니다. 반대로 URL이 'NOINDEX'로 표시됨에 첫 화면이나 메뉴 페이지가 들어 있다면 가장 먼저 고쳐야 합니다. 홈페이지 빌더의 '검색엔진 노출 안 함', '비공개' 같은 설정이 켜진 채로 공개된 경우가 흔합니다.

4'크롤링됨'과 '발견됨'은 무엇이 다른가요?

이름이 비슷해서 가장 헷갈리는 두 사유입니다. 차이는 구글이 페이지를 열어 봤느냐입니다.

  • 발견됨 - 현재 색인이 생성되지 않음: 구글이 주소는 알지만 아직 열어 보지 않았습니다. 고객센터는 새 페이지 크롤링에 일주일 정도 걸릴 수 있다고 안내합니다. 새로 만든 페이지라면 우선 기다립니다.
  • 크롤링됨 - 현재 색인이 생성되지 않음: 구글이 열어 봤지만 지금은 색인에 올리지 않기로 했습니다. 중요한 페이지가 여기 있으면 내용을 살펴봅니다.

'크롤링됨'에 중요한 페이지가 있을 때 흔한 원인은 이렇습니다(일반 요령). 본문이 사진 한 장뿐이라 글자가 거의 없거나, 다른 페이지와 내용이 거의 같거나, 지난해 이벤트 페이지처럼 비슷한 페이지가 여러 개 남아 있는 경우입니다. 메뉴 · 가격표를 사진으로만 올렸다면 핵심 내용을 글자로도 적고, 겹치는 옛 페이지는 정리합니다. 옛 페이지를 지울지 301 로 넘길지는 연말 페이지 정리 · 404 · 410 · 301 글을 참고하세요.

5404 는 전부 고쳐야 하나요?

아닙니다. 고객센터는 이렇게 안내합니다.

일반적으로 직접 연결되거나 사이트맵에 나열되는 404 오류만 수정하는 것이 좋습니다.— Search Console 고객센터 「페이지 색인 생성 보고서」

즉, 우리 홈페이지 메뉴 · 본문 · 사이트맵에서 링크가 걸려 있는데 404 가 나는 주소만 고치면 됩니다. 손님이 눌렀다가 빈 화면을 보는 주소이기 때문입니다. 반대로 몇 년 전 지운 페이지, 다른 사이트가 잘못 적어 둔 주소는 404 로 둬도 됩니다. 지운 페이지를 대신할 새 페이지가 있다면 그때만 301 로 넘깁니다.

  • 메뉴 · 버튼 링크가 404 → 링크 주소를 바르게 고치기
  • 사이트맵에 지운 페이지가 남아 있음 → 사이트맵에서 빼기
  • 대신할 새 페이지가 있음 → 옛 주소를 새 주소로 301
  • 대신할 페이지가 없고 링크도 없음 → 그대로 둠

6고친 다음에는 무엇을 누르나요?

사유 하나를 열어 원인을 고쳤다면 그 사유 화면의 수정 결과 확인을 누릅니다. 고객센터 안내에 따르면 확인에는 일반적으로 최대 2주가 걸립니다.

  1. 사유를 열고 예시 URL 중 중요한 페이지의 원인을 고칩니다.
  2. 그 주소를 URL 검사의 실제 URL 테스트로 확인해 문제가 풀렸는지 봅니다.
  3. 사유 화면에서 '수정 결과 확인'을 한 번 누릅니다.
  4. 2주 안에 결과 안내가 오면 확인합니다. 그 사이 같은 버튼을 다시 누르지 않습니다.
  5. 중요한 페이지가 '색인이 생성됨'으로 바뀌면, 실제로 노출 · 클릭이 생기는지 실적 보고서에서 봅니다.

노출 · 클릭 숫자를 읽는 법은 Search Console 실적 보고서 클릭 · 노출 · CTR 글에 있습니다. 우리 홈페이지가 구글이 읽기 좋은 구조인지 한 번에 보고 싶다면 무료 SEO 점검에 주소를 넣어 보세요. 큰길브리지는 홈페이지 제작과 검색 노출 정리를 전국 비대면으로 진행합니다.

자주 묻는 질문

Search Console 에 색인 생성 안 됨 페이지가 많으면 순위가 떨어지나요?

숫자 자체는 문제가 아닙니다. 리디렉션되는 옛 주소, 일부러 noindex 를 건 페이지, 링크 없는 404 는 색인에 없는 것이 정상입니다. 손님이 찾아야 할 중요한 페이지가 목록에 있는지만 확인하면 됩니다.

'발견됨 - 현재 색인이 생성되지 않음'은 어떻게 해야 하나요?

구글이 주소를 알지만 아직 크롤링하지 않은 상태입니다. 새 페이지 크롤링에는 일주일 정도 걸릴 수 있으니 새 페이지라면 우선 기다리고, 중요한 페이지라면 첫 화면 · 메뉴에서 링크를 걸어 둡니다.

404 오류는 모두 고쳐야 하나요?

아닙니다. 고객센터는 일반적으로 직접 연결되거나 사이트맵에 나열되는 404 오류만 수정하는 것이 좋다고 안내합니다. 링크도 없고 대신할 페이지도 없는 옛 주소는 그대로 둬도 됩니다.

수정 결과 확인은 얼마나 걸리나요?

고객센터 안내에 따르면 일반적으로 최대 2주가 걸립니다. 그 사이 같은 버튼을 반복해서 누를 필요는 없습니다.
