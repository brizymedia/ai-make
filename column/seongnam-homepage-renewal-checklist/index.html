성남 홈페이지 리뉴얼홈페이지 리뉴얼 시기모바일 중심 색인Core Web Vitals 기준

성남 홈페이지 리뉴얼을 고민한다면 디자인이 낡았는지보다 네 가지를 먼저 보십시오. 휴대폰에서 내용이 PC와 똑같이 보이는지, 첫 화면이 빨리 뜨는지, 주소가 https로 열리는지, 전화번호와 영업 정보가 지금과 맞는지입니다. 둘 이상이 어긋나면 부분 수정보다 리뉴얼이 낫고, 하나뿐이라면 그 부분만 고쳐도 됩니다.

핵심만 먼저
  • 구글은 스마트폰 에이전트로 크롤링한 모바일 버전 콘텐츠로 색인과 순위를 정합니다(모바일 중심 색인 생성). 휴대폰에서 빠진 내용은 검색에서도 빠진다고 보면 됩니다.
  • Core Web Vitals의 '좋음' 기준은 LCP 2.5초 이내, INP 200밀리초 이하, CLS 0.1 이하이며, 방문의 75번째 백분위수로 판단합니다(web.dev).
  • 구글 페이지 경험 자체 평가에는 '페이지가 안전하게 제공되나요?', '콘텐츠가 휴대기기에서 제대로 표시되나요?'라는 질문이 들어 있습니다.
  • 리뉴얼로 주소가 바뀌면 옛 주소에서 새 주소로 301 리디렉션을 걸어야 그동안 쌓인 검색 노출을 잃지 않습니다.

1리뉴얼이 필요하다는 신호는 무엇인가요?

아래 표에서 '예'가 두 개 이상이면 전체 리뉴얼을, 하나면 해당 부분 수정을 먼저 검토합니다. 확인은 사장님 휴대폰 하나로 10분이면 됩니다.

점검 항목휴대폰으로 확인하는 법문제가 되는 모습
모바일 화면홈페이지를 휴대폰으로 열어 메뉴를 전부 눌러 본다PC 화면이 작게 줄어 보이거나, 모바일에서는 일부 메뉴 · 글이 빠져 있음
로딩 속도와이파이를 끄고 데이터로 첫 화면이 뜨는 시간을 잰다하얀 화면이 오래 보이거나, 뜨는 도중 글자와 버튼이 밀려 내려감
HTTPS주소창에 http:// 로 직접 쳐서 들어가 본다https로 넘어가지 않거나 '주의 요함' 표시가 뜸
연락처 · 정보전화 버튼을 눌러 보고 주소 · 영업시간을 지금과 비교한다없어진 번호, 이사 전 주소, 끝난 이벤트 배너가 남아 있음

2휴대폰 화면은 왜 PC보다 먼저 보나요?

구글 검색 센터 문서는 '색인을 생성하고 순위를 지정하는 데 스마트폰 에이전트로 크롤링된 모바일 버전의 콘텐츠를 사용'한다고 설명하고, 이를 모바일 중심 색인 생성이라고 부릅니다. 같은 문서는 모바일 사이트에 데스크톱 사이트와 동일한 콘텐츠가 들어 있는지 확인하라고 권합니다.

오래된 홈페이지에서 흔한 문제는 PC용과 모바일용을 따로 만들어 모바일 쪽에 글을 줄여 둔 경우입니다. 그러면 PC에만 있는 시술 설명이나 제품 안내는 검색에서 힘을 잃습니다. 리뉴얼할 때는 한 페이지가 화면 크기에 맞춰 바뀌는 방식으로 만들어 두 버전의 내용을 하나로 합치는 것이 관리도 쉽습니다.

3속도는 어떤 숫자를 기준으로 판단하나요?

2.5초LCP 좋음 기준 — 가장 큰 콘텐츠가 뜨기까지(web.dev)
200msINP 좋음 기준 — 눌렀을 때 반응까지(web.dev)
0.1CLS 좋음 기준 — 화면 밀림 정도(web.dev)

web.dev는 Core Web Vitals를 로드 성능(LCP), 상호작용성(INP), 시각적 안정성(CLS) 세 가지로 나누고, 모바일과 데스크톱을 구분해 페이지 로드의 75번째 백분위수가 기준을 넘도록 하라고 안내합니다. 방문 네 번 중 세 번 이상이 기준 안에 들어야 한다는 뜻입니다.

구글 검색 센터는 Search Console의 Core Web Vitals 보고서로 사이트 성능을 확인하라고 권하고, 이 지표가 핵심 순위 시스템이 보상하려는 것과 일치한다고 설명합니다. 오래된 홈페이지에서 숫자를 끌어내리는 원인은 대개 줄이지 않은 큰 사진, 첫 화면의 자동 재생 슬라이드, 쓰지 않는 외부 스크립트입니다.

4HTTPS와 방해 요소는 어떻게 확인하나요?

구글 검색 센터의 페이지 경험 문서에는 사이트 운영자가 스스로 물어볼 질문이 정리되어 있습니다. 리뉴얼 전후에 그대로 점검표로 쓰기 좋습니다.

  • 페이지가 안전하게 제공되나요? — http로 들어와도 https로 넘어가는지 봅니다.
  • 콘텐츠가 휴대기기에서 제대로 표시되나요? — 글자를 확대하지 않고 읽을 수 있는지 봅니다.
  • 핵심 콘텐츠를 방해하거나 주의를 분산시키는 과도한 광고를 쓰지 않나요?
  • 방해가 되는 전면 광고를 쓰지 않나요? — 들어오자마자 화면을 가리는 팝업이 대표적입니다.

도메인과 HTTPS 연결을 처음부터 이해하고 싶다면 도메인 · DNS · HTTPS 정리 글을 함께 보십시오.

5리뉴얼할 때 검색 노출을 지키는 순서는?

새로 만드는 것보다 어려운 것이 그동안 쌓인 검색 노출을 옮기는 일입니다. 아래 순서를 지키면 리뉴얼 직후 방문이 뚝 떨어지는 일을 줄일 수 있습니다.

  1. 지금 주소 목록을 뽑아 둡니다. 검색으로 들어오는 페이지(서비스 소개, 오시는 길 등)의 주소를 전부 적습니다.
  2. 새 주소와 짝을 짓습니다. 옛 주소 하나마다 가장 비슷한 새 페이지를 정합니다. 전부 첫 화면으로 보내지 않습니다.
  3. 301 리디렉션을 겁니다. 구글 검색 센터는 URL이 바뀌는 사이트 이전 때 301 리디렉션을 가능한 오래(일반적으로 최소 1년) 유지하라고 안내합니다.
  4. 연락처와 영업 정보를 한 번에 맞춥니다. 홈페이지 하단, 지도 서비스, SNS 소개란의 전화번호 · 주소 · 영업시간을 같은 날 고칩니다.
  5. 사이트맵을 다시 제출하고 지켜봅니다. 서치콘솔과 서치어드바이저에서 새 사이트맵을 제출하고, 몇 주간 색인 상태를 확인합니다.

리뉴얼 전 지금 상태를 숫자로 남겨 두면 비교가 쉽습니다. 무료 SEO 점검에 현재 주소를 넣어 결과를 저장해 두십시오.

6성남 사장님이 리뉴얼 전에 참고할 곳은?

리뉴얼은 누구에게 무엇을 팔지 다시 정리할 좋은 기회입니다. 시 빅데이터 포털의 소상공인 상권정보시스템(시와 소상공인시장진흥공단 표기)에는 상권분석(간단분석 · 상세분석), 상권현황(배달지도 · 상권지도), 창업기상도, 상권통계(매출추이 · 업소현황 · 업력현황) 메뉴가 있습니다. 우리 동네 업종 흐름을 보고 첫 화면 문구와 주력 서비스를 고르는 데 참고할 수 있습니다.

시정소식지 비전성남은 2026년 7월 「청년 창업 재도약(마케팅) 지원」 모집을 안내했습니다. 관내 거주 · 관내 창업 1년 이상인 19~39세 청년 소상공인을 대상으로 마케팅 역량 강화 교육 · 컨설팅과 맞춤형 마케팅 활용품 제작을 지원하는 사업이었고, 접수는 7월 22일에 마감됐습니다. 비슷한 사업이 다시 열리는지 시 누리집과 소식지를 확인하십시오.

큰길브리지는 성남 홈페이지 리뉴얼도 전국 비대면으로 진행합니다. 지금 홈페이지 주소와 바뀐 연락처 · 영업 정보를 제작 문의에 남겨 주시면 위 점검표 기준으로 고칠 곳부터 정리해 드립니다.

자주 묻는 질문

디자인만 바꾸면 검색 노출도 좋아지나요?

디자인 변경만으로는 달라지지 않을 수 있습니다. 모바일에서 내용이 빠지지 않는지, Core Web Vitals 기준을 넘는지, https로 안전하게 제공되는지를 함께 고쳐야 효과가 있습니다.

리뉴얼하면 기존 검색 순위가 떨어지나요?

주소가 바뀌는데 리디렉션을 걸지 않으면 떨어지기 쉽습니다. 옛 주소마다 새 주소로 301 리디렉션을 걸고, 구글 안내대로 가능한 오래(일반적으로 최소 1년) 유지하십시오.

속도 점수는 어디서 확인하나요?

구글 서치콘솔의 Core Web Vitals 보고서에서 실제 방문 기준 결과를 볼 수 있습니다. 서치콘솔 등록 전이라면 무료 SEO 점검으로 현재 상태를 먼저 확인할 수 있습니다.

홈페이지를 만든 업체와 연락이 안 되는데 리뉴얼할 수 있나요?

도메인과 호스팅 계정이 누구 이름으로 되어 있는지부터 확인하십시오. 도메인 소유자가 사장님이면 새 홈페이지로 옮길 수 있고, 아니라면 등록대행자에게 소유자 변경 절차를 먼저 문의해야 합니다.
