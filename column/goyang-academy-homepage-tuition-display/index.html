고양 학원 홈페이지에서 가장 먼저 챙길 것은 교습비 표시입니다. 학원법 제15조는 학습자를 모집하려고 인쇄물 · 인터넷으로 광고할 때 교습비등과 등록 내용 중 정해진 사항을 표시하게 하고, 고양교육지원청은 이 인터넷 광고에 홈페이지 · 블로그 · 카페 · SNS · 네이버플레이스가 전부 포함된다고 안내합니다. 표시 항목을 먼저 자리 잡고, 그 위에 커리큘럼으로 신뢰를 쌓는 순서가 좋습니다.

핵심만 먼저
  • 학원법 제15조 제3항: 인쇄물 · 인터넷 등으로 학습자 모집 광고를 하면 교습비등과 등록증명서 내용 중 대통령령으로 정한 사항을 표시해야 합니다.
  • 표시할 사항은 교습비등, 등록증명서의 등록 번호, 학원의 명칭, 교습과정 또는 교습과목 네 가지입니다(시행령 제16조의3, 법제처 생활법령 안내).
  • 고양교육지원청은 인터넷 광고에 홈페이지 · 블로그 · 카페 · SNS · 네이버플레이스가 모두 포함되며, 해시태그 SNS 광고에서 표시 누락이 잦다고 안내합니다.
  • 교습비를 거짓으로 표시하거나 표시한 금액을 넘겨 받으면 행정처분과 과태료 대상이 됩니다(제15조 제4항).

1. 학원 홈페이지도 '광고'로 보나요?

네. 학원법 제15조 제3항은 '학습자를 모집할 목적으로 인쇄물 · 인터넷 등을 통하여 광고를 하는 경우' 표시 의무를 둡니다. 고양교육지원청 학원운영안내는 여기서 말하는 인터넷 광고에 홈페이지, 블로그, 카페, SNS, 네이버플레이스가 전부 포함된다고 적고 있습니다. 수강생 모집 안내가 있는 페이지라면 표시 항목이 들어가야 한다고 보면 됩니다.

같은 조항은 교습자(교습소)와 개인과외교습자에게도 적용됩니다. 교습소를 운영하는 원장님도 홈페이지나 블로그로 모집 글을 올린다면 같은 기준으로 점검하십시오.

2. 홈페이지에 반드시 보여야 하는 표시 항목은 무엇인가요?

법제처 찾기쉬운 생활법령정보는 시행령 제16조의3에 따른 표시 사항을 네 가지로 정리합니다. 홈페이지 어디에 두면 좋은지까지 함께 적었습니다.

표시 항목근거홈페이지에서 두기 좋은 곳
교습비등학원법 제15조 제3항과정 안내 페이지의 과목별 표, 모든 페이지 하단에서 이어지는 링크
등록증명서의 등록 번호시행령 제16조의3모든 페이지 하단(사업자 정보 옆)
학원의 명칭시행령 제16조의3상단 로고 옆과 하단에 등록된 명칭 그대로
교습과정 또는 교습과목시행령 제16조의3과정 안내 페이지 제목, 교습비 표의 첫 칸
교습비등이 바뀌면 교육지원청에 변경 등록을 먼저 하고, 홈페이지 숫자도 같은 날 고칩니다. 등록한 금액과 홈페이지 금액이 다르면 '거짓 표시'로 볼 여지가 생깁니다.
교습비 표를 사진 한 장으로만 올리면 휴대폰에서 글자가 작아 안 보이고 검색에도 잡히지 않습니다. 표는 글자로 만들어 두는 편이 표시 의무 면에서도, 검색 면에서도 낫습니다.

4. 후기 대신 무엇으로 신뢰를 보여 주나요?

합격 수기나 학부모 후기는 확인이 어렵고, 숫자를 부풀리면 과대광고가 됩니다. 대신 학부모가 상담 전에 궁금해하는 것을 커리큘럼 페이지로 미리 보여 주면 상담 전화의 질이 달라집니다.

  1. 학년 · 수준별 과정표 — 과정명, 대상, 주당 수업 횟수와 시간, 사용 교재를 한 표에 둡니다.
  2. 한 달 수업 흐름 — 1주차 개념, 2주차 문제 풀이처럼 수업이 어떻게 흘러가는지 보여 줍니다.
  3. 평가와 피드백 방식 — 테스트 주기, 학부모에게 결과를 알리는 방법을 적습니다.
  4. 강사 소개 — 과목과 담당 과정 중심으로, 교육지원청에 등록된 강사 기준으로 적습니다.
  5. 보충 · 결석 규칙과 반환 기준 — 교습비등 반환기준은 원내 게시 대상이기도 하니 홈페이지에도 같은 내용을 둡니다.

과정표는 교습비 표시 항목과 한 페이지에 묶으면 관리가 쉽습니다. 과정이 바뀔 때 한 곳만 고치면 되기 때문입니다.
