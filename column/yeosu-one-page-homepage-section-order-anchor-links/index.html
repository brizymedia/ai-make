여수 원페이지 홈페이지는 '손님이 전화로 묻는 순서'대로 섹션을 쌓고, 위쪽 메뉴를 같은 페이지 안 앵커 링크(#)로 연결하는 구성이 기본입니다. 객실 · 메뉴 · 오시는 길 · 예약 안내 정도로 끝나는 가게에는 잘 맞습니다. 반대로 검색에서 따로 찾혀야 할 주제가 여러 개라면, 구글이 # 뒤 주소를 별도 페이지로 다루지 않는다는 점 때문에 그 주제만 페이지를 나누는 편이 낫습니다.

핵심만 먼저
  • 섹션 순서는 첫 화면(무엇 · 어디) → 대표 상품 → 위치 · 오시는 길 → 이용 안내 → 자주 묻는 질문 → 연락처처럼 손님 질문 순서를 따릅니다(일반적인 요령).
  • 앵커 메뉴는 href가 있는 진짜 a 링크로 만들고, 위에 고정된 메뉴 줄이 섹션 제목을 가리지 않게 여백을 둡니다.
  • 구글 검색은 일반적으로 URL 프래그먼트(# 뒤)를 지원하지 않으므로 #rooms, #location은 검색에서 별도 페이지가 아닙니다.
  • 구글은 페이지마다 내용을 설명하는 고유한 제목을 두라고 안내합니다. 원페이지는 제목이 하나뿐이라 주제를 많이 담을수록 제목이 흐려집니다.

1원페이지 홈페이지가 맞는 가게는 어떤 곳인가요?

원페이지 홈페이지는 메뉴를 눌러도 다른 페이지로 넘어가지 않고 한 장 안에서 아래로 이동하는 홈페이지입니다. 광고 · 문자로 들어온 사람에게 제안 하나만 보여 주는 랜딩페이지와는 목적이 다릅니다. 랜딩페이지 배치는 대전 랜딩페이지 글에 따로 정리했습니다.

가게 상황원페이지로 충분한가이유(일반적인 판단)
객실 2~3개 펜션, 메뉴가 짧은 횟집충분손님 질문이 위치 · 가격표 · 예약 방법 몇 가지로 끝남
1인 공방 · 교습소충분소개 · 수업 · 신청이 한 흐름
산단 협력업체 회사소개대체로 충분연혁 · 설비 · 인증 · 오시는 길을 한 장에 정리 가능
시술 · 진료 과목이 여러 개인 병원 · 미용실나누는 편이 나음과목마다 따로 검색되어야 함
공지 · 후기 · 이벤트가 자주 바뀌는 가게나누는 편이 나음한 장이 계속 길어지고 오래된 글이 위에 남음

2섹션은 어떤 순서로 쌓아야 하나요?

전화로 가장 먼저 묻는 것이 가장 위로 갑니다. 바닷가 펜션을 예로 들면 다음 순서가 출발점입니다(일반적인 요령). 섹션 하나에는 질문 하나만 답합니다.

  1. 첫 화면 — 가게 이름보다 '무엇을, 어디서'가 먼저 보이게 씁니다. 예: '돌산 바다 앞 독채 펜션'.
  2. 대표 상품 — 객실 · 대표 메뉴를 사진과 한 줄 설명으로. 가격표가 자주 바뀌면 날짜를 붙입니다.
  3. 위치 · 오시는 길 — 주소 글자, 지도, 주차 여부. 지도 이미지 안에만 주소를 넣지 말고 글자로도 씁니다.
  4. 이용 안내 — 입실 · 퇴실 시간, 예약 · 환불 규정, 반려동물 가능 여부처럼 다툼이 생기는 내용.
  5. 자주 묻는 질문 — 지난달 문의에서 반복된 질문 서너 개.
  6. 연락처 — 전화 · 카카오톡 · 예약 버튼과 영업시간. 첫 화면 버튼과 같은 문구로 씁니다.

3위쪽 메뉴를 앵커 링크로 만들 때 무엇을 지키나요?

앵커 링크는 메뉴를 누르면 같은 페이지의 해당 섹션으로 내려가게 하는 링크입니다. 예를 들어 메뉴 '오시는 길'에 #location을 걸고, 오시는 길 섹션에 같은 이름표(id)를 붙입니다.

  • 진짜 링크로 만듭니다. Google 검색 센터는 일반적으로 href 속성이 있는 a 요소만 링크로 크롤링할 수 있다고 안내합니다. 클릭 이벤트로만 스크롤시키는 버튼보다 a href="#location" 형태의 링크가 안전합니다.
  • 이름표는 짧은 영문으로. #rooms, #location, #faq처럼 바꾸지 않을 이름을 씁니다. 손님이 '오시는 길' 부분만 카톡으로 공유하기도 하니 이름을 자주 바꾸지 않습니다(일반적인 요령).
  • 고정 메뉴 줄이 제목을 가리지 않게. 화면 위에 붙어 있는 메뉴 줄이 있으면, 이동한 섹션의 제목이 그 밑에 숨습니다. CSS scroll-margin-top으로 섹션 위에 여백을 주는 방법이 흔히 쓰이며, MDN은 이 속성이 2021년 4월부터 주요 브라우저에서 쓰인다고 표시합니다.
  • 메뉴 이름은 섹션 제목과 같게. 메뉴는 '오시는 길'인데 섹션 제목이 'LOCATION'이면 손님이 제대로 왔는지 헷갈립니다. 메뉴 이름 짓는 법은 평택 메뉴 구조 글을 참고하십시오.

4휴대폰에서 한 장이 길어지면 어떻게 하나요?

PC에서는 짧아 보여도 휴대폰에서는 사진이 세로로 쌓여 몇 배로 길어집니다. 아래 세 가지를 확인합니다.

  • 누르는 칸 크기 — 웹 접근성 지침 WCAG 2.2의 성공 기준 2.5.8(AA)은 누르는 대상을 최소 24×24 CSS 픽셀로 두라고 정합니다(문장 속 링크 등 예외 있음). 앵커 메뉴 글자 사이가 촘촘하면 엉뚱한 섹션으로 내려갑니다.
  • 사진은 섹션마다 대표 한두 장 — 객실 사진을 전부 펼치기보다 대표 사진과 '사진 더 보기'로 나눕니다(일반적인 요령).
  • 맨 위로 돌아가는 길 — 긴 페이지 끝에는 메뉴로 돌아가는 링크를 두어 손님이 다시 위로 끌어올리지 않게 합니다.

5한 페이지에 여러 주제를 넣으면 검색에서 무엇이 불리한가요?

Google 검색 센터의 URL 구조 문서는 'Google 검색은 일반적으로 URL 프래그먼트를 지원하지 않습니다'라고 적고, 프래그먼트로 페이지 내용을 바꾸지 말라고 안내합니다. 원페이지의 #rooms, #location은 손님에게는 편한 지름길이지만, 검색에서는 결국 주소 하나 · 제목 하나짜리 페이지입니다.

제목 링크 문서는 사이트의 각 페이지마다 title 요소에 내용을 설명하는 고유한 텍스트를 두고, 구체적이고 간결하게 쓰라고 합니다. 주제가 다섯 개인 원페이지는 그 다섯 개를 한 제목에 다 넣을 수 없습니다. 아래 표로 따로 페이지가 필요한 주제를 골라 보십시오.

손님이 검색하는 말(예)원페이지 안에서따로 페이지가 나은 경우(일반적인 판단)
가게 이름, '돌산 독채 펜션'첫 화면 · 제목으로 충분—
'돌산 단체 숙소 바비큐'이용 안내 한 줄로는 약함단체 손님 매출 비중이 크다면 단체 안내 페이지
기간 한정 행사 · 패키지위쪽 띠 공지로 충분행사명으로 검색 유입을 노린다면 행사 안내 페이지
업종이 다른 두 사업(펜션 + 카페)한 제목에 담기 어려움사업마다 페이지 분리
처음엔 원페이지로 시작하고, 문의가 몰리는 주제가 생기면 그 주제만 한 장을 더 만드는 방식이 관리하기 쉽습니다. 지금 페이지의 제목 · 설명이 어떻게 잡혀 있는지는 무료 SEO 점검으로 볼 수 있습니다.

6여수 섬박람회 같은 기간 안내는 어디에 넣나요?

여수시청 누리집 첫 화면에는 2026여수세계섬박람회(주제 '섬, 바다와 미래를 잇다', 2026년 9월 5일~11월 4일, 돌산 진모지구 · 엑스포장 · 개도 · 금오도 일원) 안내와 함께, 같은 기간 시내버스 무료운행 소식, 10월 31일(토) 저녁 7시 세계박람회장 일원에서 해상 불꽃쇼로 열리는 밤바다 불꽃축제 안내가 올라 있습니다.

이런 기간 안내는 원페이지의 첫 화면 바로 아래에 얇은 띠로 넣고, '박람회장까지 가는 길'처럼 손님에게 필요한 한 줄만 적는 편이 깔끔합니다(일반적인 요령). 행사가 끝나면 그날 바로 지웁니다. 끝난 행사 안내가 첫 화면에 남아 있으면 가게 정보 전체가 오래돼 보입니다. 박람회 · 축제 이름을 쓸 때는 가게가 주최 · 협찬하는 것처럼 보이지 않게 '박람회 기간 안내'처럼 사실대로 씁니다.

여수는 큰길브리지가 직접 방문 상담하는 지역입니다. 지역 안내는 지역 페이지에 있고, 섹션 순서를 함께 잡고 싶다면 가게 사진과 자주 받는 질문을 제작 문의에 남겨 주십시오.

자주 묻는 질문

원페이지 홈페이지도 구글 · 네이버 검색에 나오나요?

나옵니다. 다만 구글은 일반적으로 URL의 # 뒤 부분을 지원하지 않으므로 섹션마다 따로 검색 결과에 잡히지는 않습니다. 페이지 하나가 제목 하나로 검색된다고 보면 됩니다.

메뉴를 누르면 부드럽게 내려가는 효과는 꼭 필요한가요?

필수는 아닙니다. 중요한 것은 메뉴가 href가 있는 진짜 링크인지, 이동한 뒤 섹션 제목이 고정 메뉴 줄에 가리지 않는지입니다.

나중에 페이지를 나누면 처음부터 다시 만들어야 하나요?

보통은 아닙니다. 원페이지의 한 섹션을 새 페이지로 떼어 내고, 원래 자리에는 요약과 새 페이지 링크를 남기는 방식으로 늘릴 수 있습니다(일반적인 방법).

여수에서는 직접 만나서 상담할 수 있나요?

네. 순천 · 광양 · 고흥 등과 함께 직접 방문하는 지역입니다. 그 밖의 지역은 전국 비대면으로 진행합니다.
