강릉 홈페이지 리뉴얼에서 가장 조용히 손해를 보는 순간은 주소가 바뀔 때입니다. 옛 주소마다 가장 비슷한 새 주소를 하나씩 짝지어 서버에서 301 리디렉션을 걸고, 도메인 자체가 바뀌었다면 Search Console 주소 변경 도구와 네이버 서치어드바이저 등록까지 마쳐야 그동안 쌓인 검색 노출이 새 홈페이지로 넘어갑니다. 리뉴얼할지 말지 판단하는 점검은 별도 글에 있고, 이 글은 '옮기는 날'의 순서만 다룹니다.

핵심만 먼저
  • 구글은 옛 주소 목록을 만들어 각 주소를 어디로 보낼지 정하라고 안내하며, 여러 옛 주소를 홈페이지 첫 화면처럼 관련 없는 한 곳으로 몰아 보내지 말라고 합니다.
  • 리디렉션은 서버 측 영구 리디렉션(301)이 기본이고, 구글은 가능한 오래, 일반적으로 최소 1년 유지하라고 권합니다.
  • Search Console 주소 변경 도구는 도메인이나 하위 도메인이 바뀔 때만 씁니다. http→https, www 붙이기, 같은 도메인 안 경로 변경에는 필요 없습니다.
  • 네이버는 옛 주소와 새 주소를 URL 기준 1:1로 맞추고, 이전이 끝나기 전에 옛 사이트를 robots.txt로 막거나 서버를 먼저 끄지 말라고 안내합니다.

1리뉴얼하면 어떤 경우에 '주소가 바뀐다'고 보나요?

1년301 리디렉션 권장 최소 유지 기간(Google 사이트 이전 문서, 일반적인 경우)
180일주소 변경 도구 요청 후 이전 알림 · 신호 전달 기간(Search Console 고객센터)
2~3일바뀐 도메인을 네이버 검색로봇이 인식하는 데 걸릴 수 있는 최소 기간(서치어드바이저)

디자인만 바꾸고 주소가 그대로면 이 글의 작업은 대부분 필요 없습니다. 아래 표에서 우리 리뉴얼이 어느 줄에 해당하는지 먼저 고르십시오.

바뀌는 것예시301 리디렉션구글 주소 변경 도구

리뉴얼 자체가 필요한지(모바일 · 속도 · HTTPS · 연락처)는 성남 홈페이지 리뉴얼 점검표에, 도메인을 새로 사는 과정은 춘천 도메인 등록 글에 정리했습니다.

2옛 주소와 새 주소는 어떻게 짝짓나요?

구글 검색 센터의 'URL 변경이 수반되는 사이트 이전' 문서는 이전 URL 목록을 만든 뒤 각 URL을 리디렉션할 위치를 정하라고 안내합니다. 목록은 사이트맵, 서버 로그, 분석 도구, Search Console의 링크 정보에서 뽑고, 사진 · 동영상 · PDF 같은 파일 주소도 넣으라고 합니다. 메뉴판 PDF나 약도 이미지가 외부 블로그에 링크돼 있다면 그것도 짝을 지어야 합니다.

가게 홈페이지라면 엑셀 두 칸이면 충분합니다. 왼쪽에 옛 주소, 오른쪽에 새 주소를 적고, 오른쪽이 비는 줄이 없게 채웁니다(일반적인 방법).

옛 주소(예)새 주소(예)판단
/sub01.php?id=room1/rooms/ocean/같은 객실 소개 → 1:1로 보냄
/board/notice.php?no=12/notice/2026-winter-hours/같은 공지 → 1:1로 보냄
/data/menu.pdf/files/menu-2026.pdf파일도 짝지음
/event/summer2024/없음끝난 행사 → 첫 화면으로 몰지 말고 404 또는 가장 가까운 안내 페이지 검토
구글은 여러 옛 URL을 새 사이트의 홈페이지처럼 관련성이 떨어지는 단일 URL로 전부 리디렉션하지 말라고 안내합니다. 방문자를 혼란스럽게 하고 '소프트 404'로 처리될 수 있기 때문입니다.

3리디렉션은 어떻게 걸고, 얼마나 두나요?

  • 서버 측 301이 기본입니다. 구글은 가능하면 서버 측 영구 리디렉션을 쓰고, 화면에서 자바스크립트로 넘기는 방식은 최후의 수단으로 두라고 합니다.
  • 한 번에 도착하게 합니다. 옛 주소 → 중간 주소 → 새 주소처럼 여러 번 거치는 리디렉션 체인을 피하고, 최종 페이지로 바로 보냅니다.
  • 새 페이지에는 자기 자신을 가리키는 대표 주소(canonical)를 답니다. 구글과 네이버 문서 모두 같은 내용을 안내합니다. 네이버는 이렇게 해야 새 사이트의 노출 주소가 옛 도메인으로 잡히는 일을 막는다고 설명합니다.
  • 최대한 오래 둡니다. 구글은 일반적으로 최소 1년을 권하고, 주소 변경 도구 도움말은 옛 도메인 등록을 최소 1년 유지하라고 권합니다. 리뉴얼 다음 해 도메인 갱신 안내를 놓치지 마십시오.
네이버 서치어드바이저는 이전이 끝날 때까지 옛 사이트에 robots.txt를 먼저 설정하거나 서버 네트워크를 먼저 정지 · 차단하지 말라고 강조합니다. 검색로봇이 옛 주소에 들어와 봐야 옮겨졌다는 사실을 알 수 있기 때문입니다.

4Search Console 주소 변경 도구는 언제, 어떻게 쓰나요?

도메인이나 하위 도메인이 바뀌었을 때만 씁니다. 쓰기 전 조건은 세 가지입니다.

  1. 옛 사이트와 새 사이트 모두 같은 Google 계정으로 소유자 확인이 되어 있어야 합니다. 도메인 수준 속성에서만 쓸 수 있습니다.
  2. 옛 홈페이지에서 새 홈페이지로, 가능하면 주요 페이지마다 301 리디렉션이 먼저 걸려 있어야 합니다.
  3. 옛 사이트 속성에서 도구를 열고 이동 전 점검을 통과하면 요청이 제출됩니다. www가 붙은 주소 등 확인된 변형이 여럿이면 각각 요청합니다.

요청 후 구글은 180일 동안 옛 사이트보다 새 사이트의 크롤링 · 색인에 집중하고 신호를 넘긴다고 설명합니다. 같은 기간에는 이동을 취소할 수도 있습니다. 새 사이트맵은 Search Console에 제출하고, 구글 문서에 따르면 이 시점에 이전 사이트맵은 삭제할 수 있습니다.

5네이버 서치어드바이저에서는 무엇을 하나요?

네이버 서치어드바이저는 '웹 사이트 이전' 가이드에 아래 다섯 단계를 안내합니다. 중소규모 사이트는 모든 URL을 한 번에 옮기는 것을 권장합니다.

  1. 새 사이트로 글과 함께 이미지 · 파일까지 옮깁니다.
  2. 새 사이트에 도메인을 연결하고, 웹마스터도구의 '사이트 간단 체크'에 새 주소를 넣어 접속이 정상인지 봅니다.
  3. 새 사이트의 robots.txt를 모두 허용하고, 옛 주소에서 새 주소로 URL 1:1 301 리디렉션을 겁니다.
  4. 웹마스터도구에 새 사이트를 등록 · 소유확인하고 sitemap.xml을 제출합니다.
  5. 검색 결과에 옛 주소가 계속 보이면 웹 페이지 수집 요청을 쓰고, 유입이 없어진 뒤에 옛 서버를 끄고 옛 사이트 등록을 삭제합니다.
네이버는 대표 주소를 자주 바꾸면 사이트 품질 평가에 영향이 생기므로, 브랜드 변경처럼 꼭 필요할 때만 이전하라고 안내합니다. 리뉴얼하면서 '이참에 도메인도 바꿀까'는 한 번 더 따져 보십시오.

6강릉 사장님은 언제 옮기는 게 좋을까요?

구글 문서는 트래픽이 계절이나 요일에 따라 다르다면 트래픽이 줄어드는 시기에 이동하라고 권합니다. 이전 직후 순위가 잠시 흔들리는 것은 정상이며 시간이 지나면 안정된다고도 설명합니다.

강릉시청 누리집 첫 화면에는 제18회 커피축제(2026년 10월 21일~25일, 커피거리 및 시 일원) 안내가 걸려 있고, 커피축제 우리동네점 · 스탬프랠리 · 영수증 이벤트 같은 도시 전역 프로그램이 소개돼 있습니다. 시 관광 누리집에도 10월 12일자로 커피축제, ITS 세계총회, 제5회 국수축제 개최 안내가 올라왔습니다. 손님이 몰리는 이런 기간에는 주소 이전을 시작하지 말고, 행사가 끝난 뒤 한산한 주에 옮기는 편이 안전합니다.

참고로 시 대표 주소(www.gn.go.kr)는 시청(/www/), 관광(/tour/), 예약(/yeyak/)처럼 한 도메인 아래 경로로 갈래를 나눕니다. 이런 구조에서 경로 하나를 바꾸는 일은 1번 표의 '같은 도메인 안 경로'에 해당해, 주소 변경 도구 없이 리디렉션과 사이트맵으로 처리합니다.

7옮긴 뒤 몇 주 동안은 무엇을 확인하나요?

  1. 짝짓기 표의 옛 주소를 몇 개 골라 직접 열어 보고, 새 주소로 한 번에 넘어가는지 봅니다. 구글은 URL 검사 도구로 하나씩 테스트할 수 있다고 안내합니다.
  2. 홈페이지 안 링크, 인스타 · 블로그 프로필 링크, 지도 서비스의 홈페이지 칸, 광고 링크를 새 주소로 바꿉니다.
  3. Search Console 색인 보고서에서 새 사이트맵의 색인 수가 늘고 옛 주소가 줄어드는지 봅니다. 구글은 중소형 사이트가 몇 주 걸릴 수 있다고 설명합니다.
  4. 네이버 웹마스터도구에서 새 사이트의 수집 · 색인 현황을 같은 주기로 확인합니다.

옮기기 전 지금 상태를 무료 SEO 점검으로 저장해 두면 비교가 쉽습니다. 큰길브리지는 강릉 홈페이지 리뉴얼도 전국 비대면으로 진행합니다. 지금 주소와 바꿀 도메인을 제작 문의에 남겨 주시면 옛 주소 목록과 짝짓기 표부터 함께 만듭니다.

자주 묻는 질문

옛 주소를 전부 새 홈페이지 첫 화면으로 보내면 안 되나요?

구글은 여러 옛 URL을 홈페이지처럼 관련성이 떨어지는 한 곳으로 몰아 보내지 말라고 안내합니다. 소프트 404로 처리될 수 있으니 옛 주소마다 가장 비슷한 새 페이지로 1:1로 보내는 것이 기본입니다.

http를 https로만 바꿔도 주소 변경 도구를 써야 하나요?

아닙니다. Search Console 도움말은 http에서 https로 옮기거나 www 유무를 바꾸는 경우에는 이 도구를 쓰지 않고, 리디렉션 등 URL 변경 가이드라인을 따르라고 안내합니다.

옛 도메인은 리뉴얼 후 바로 해지해도 되나요?

권하지 않습니다. 구글은 리디렉션을 가능한 오래(일반적으로 최소 1년) 유지하라고 하고, 주소 변경 도구 도움말은 옛 도메인 등록을 최소 1년 유지하라고 권합니다.

강릉 지역도 방문해서 작업하나요?

전국 비대면으로 진행합니다. 전화와 온라인으로 옛 주소 목록, 도메인 · 호스팅 접속 정보를 받아 작업합니다.
