링크 보고서백링크외부 링크내부 링크

링크 보고서는 Search Console 에서 어떤 사이트가 사장님 홈페이지에 링크를 걸어 주고 있는지, 그리고 내 사이트 안에서 어떤 페이지가 링크를 많이 받는지를 보여 주는 화면입니다. 왼쪽 메뉴의 '링크'를 누르면 외부 링크와 내부 링크가 나뉘어 나옵니다. 숫자를 늘리려고 링크를 사는 것보다, 이 보고서로 예약 · 메뉴 · 오시는 길 같은 중요한 페이지가 내 사이트 안에서 충분히 연결돼 있는지 확인하는 것이 사장님이 바로 할 수 있는 일입니다.

핵심만 먼저
  • 백링크는 다른 사이트의 페이지에서 내 사이트 페이지로 연결되는 링크입니다. 링크 보고서의 외부 링크 칸에서 봅니다.
  • 외부 링크는 상위 링크된 페이지 · 상위 링크 사이트 · 상위 링크 텍스트 세 표로, 내부 링크는 내 페이지끼리 연결된 링크로 보여 줍니다.
  • 표는 최대 1,000행까지만 보이고, 내보내기로는 최대 100,000행까지 받을 수 있습니다. 보고서는 모든 링크의 전체 목록이 아닙니다.
  • 내부 링크가 적은 중요한 페이지는 첫 화면 · 메뉴 · 관련 글에서 링크를 걸어 살립니다.
  • 링크를 돈 주고 사지 않습니다. 거래처 · 지역 단체 · 블로그 후기처럼 자연스럽게 생긴 링크만 챙깁니다.

1링크 보고서에서는 무엇을 볼 수 있나요?

Search Console 고객센터는 백링크를 이렇게 설명합니다. "백링크란 내 사이트의 페이지로 연결되는 다른 사이트의 페이지에 있는 링크를 말합니다." 예를 들어 지역 상인회 홈페이지가 사장님 가게 소개 페이지로 링크를 걸어 두었다면, 그것이 백링크입니다.

이 화면은 크게 두 부분으로 나뉩니다. 외부 링크는 다른 사이트에서 내 사이트로 들어오는 링크이고, 상위 링크된 페이지 · 상위 링크 사이트 · 상위 링크 텍스트 세 표로 보여 줍니다. 내부 링크는 내 사이트 안의 페이지끼리 서로 걸린 링크입니다.

1,000행보고서 표에 보이는 최대 행 수
100,000행내보내기 버튼으로 받을 수 있는 최대 행 수

고객센터는 "표의 최대 행 수는 1,000행이므로 사이트 규모가 크거나 연결되는 사이트가 많은 경우 표가 잘릴 수 있습니다."라고 안내합니다. 소상공인 홈페이지는 대부분 이 한도에 닿지 않지만, 더 자세히 보고 싶을 때는 "내보내기 버튼을 사용하여 최대 100,000행의 데이터를 내보낼 수 있습니다."

2어디서 열고 어떤 순서로 보나요?

Search Console 에 홈페이지가 아직 등록돼 있지 않다면 서치 콘솔 첫 설정 글부터 보세요. 등록돼 있다면 아래 순서로 봅니다(화면 이름은 고객센터 기준, 순서는 일반 요령).

  1. Search Console 에 로그인하고 내 홈페이지 속성을 고릅니다.
  2. 왼쪽 메뉴 아래쪽의 '링크'를 누릅니다.
  3. 외부 링크의 '상위 링크 사이트' 표에서 어떤 사이트가 링크를 걸어 주는지 봅니다. 모르는 사이트가 있으면 주소를 눌러 어떤 글에서 링크했는지 확인합니다.
  4. '상위 링크된 페이지' 표에서 다른 사이트가 주로 내 사이트의 어느 페이지로 링크하는지 봅니다.
  5. '상위 링크 텍스트' 표에서 다른 사이트가 어떤 글자로 링크를 걸었는지 봅니다.
  6. 내부 링크 표에서 내 사이트 안에서 링크를 많이 받는 페이지와 거의 못 받는 페이지를 나눠 적습니다.
  7. 기록해 두고 싶으면 내보내기 버튼으로 표를 받아 둡니다.
링크가 하나도 안 보여도 놀라지 않습니다. 새로 만든 홈페이지는 구글이 아직 링크를 찾지 못했을 수 있습니다. 고객센터는 "보고서에는 Google에서 시간 경과에 따라 찾은 링크가 포함됩니다."라고 안내합니다.

3표마다 무엇을 보면 되나요?

세 개의 외부 링크 표와 내부 링크 표는 보는 목적이 다릅니다. 항목 이름은 고객센터 기준이고, '볼 것'과 '할 일'은 일반 요령입니다.

보고서 항목보여 주는 것사장님이 볼 것할 일
상위 링크된 페이지(외부)다른 사이트가 링크한 내 페이지첫 화면만 받는지, 메뉴 · 시술 페이지도 받는지링크 받는 페이지가 지금도 열리는지 확인
상위 링크 사이트(외부)내 사이트로 링크한 사이트거래처 · 상인회 · 블로그 등 아는 곳인지아는 곳은 정보가 맞는지 확인, 모르는 곳은 내용 확인
상위 링크 텍스트(외부)링크에 쓰인 글자가게 이름 · 업종이 들어갔는지옛 상호가 보이면 해당 사이트에 수정 부탁
내부 링크내 페이지끼리 걸린 링크예약 · 메뉴 · 오시는 길이 링크를 충분히 받는지적게 받는 중요한 페이지에 링크 추가

상위 링크 사이트 표는 사이트를 루트 도메인 단위로 묶어서 보여 줍니다. 예를 들어 www.example.com 에서 온 링크는 example.com 으로 묶여 나옵니다. 그리고 고객센터 안내대로 "중복 링크는 결합됩니다." 같은 사이트의 모든 페이지 바닥글에 링크가 있어도 그 숫자가 곧 영향력이라는 뜻은 아닙니다.

4외부 링크 숫자는 어떻게 해석하나요?

외부 링크는 많을수록 좋다고 단정하기 어렵습니다. 고객센터는 이 보고서가 "사이트의 모든 링크가 포함된 전체 목록이 아니며"라고 분명히 적습니다. 그래서 숫자 자체보다 누가, 어느 페이지로, 어떤 글자로 링크했는지를 보는 것이 쓸모 있습니다(일반 요령).

  • 지역 · 업종이 맞는 곳의 링크: 상인회, 협회, 거래처, 지역 행사 안내 페이지에서 온 링크는 손님이 실제로 눌러 들어올 가능성이 있는 링크입니다.
  • 옛 주소로 걸린 링크: 홈페이지 주소를 바꾼 적이 있다면 옛 주소로 걸린 링크가 아직 남아 있는지 봅니다. 그 페이지가 열리지 않으면 손님은 중간에서 길을 잃습니다.
  • 링크된 페이지가 색인에서 빠진 경우: 다른 사이트가 링크한 내 페이지가 검색에 안 나온다면 페이지 색인 생성 보고서에서 이유를 확인합니다.
  • 처음 보는 사이트: 대부분은 신경 쓰지 않아도 됩니다. 내용이 이상한 사이트만 따로 적어 둡니다.

외부 링크가 실제로 손님을 데려오는지는 링크 보고서만으로는 알 수 없습니다. 검색에서 몇 번 보였고 몇 번 눌렸는지는 실적 보고서에서 따로 봅니다.

5내부 링크로 중요한 페이지를 어떻게 살리나요?

사장님이 직접 고칠 수 있는 쪽은 내부 링크입니다. 내부 링크 표를 보면 첫 화면이나 메뉴처럼 모든 페이지에서 걸리는 곳은 링크를 많이 받고, 새로 만든 시술 안내나 이벤트 페이지는 거의 못 받는 경우가 많습니다. 사람도 구글도 링크를 따라 페이지를 찾기 때문에, 링크가 거의 없는 페이지는 찾기 어려워집니다(일반 요령).

  1. 내부 링크 표에서 예약 · 메뉴 · 가격 안내 · 오시는 길 · 주요 시술처럼 손님이 꼭 봐야 할 페이지를 찾습니다.
  2. 그 페이지가 받는 링크 수가 다른 페이지보다 눈에 띄게 적으면 표시해 둡니다.
  3. 첫 화면에 그 페이지로 가는 버튼이나 문장 링크를 넣습니다.
  4. 관련 있는 페이지끼리 연결합니다. 예를 들어 메뉴 페이지에서 예약 페이지로, 시술 안내에서 오시는 길로 링크를 겁니다.
  5. 링크 글자는 '여기'보다 '주차 안내 보기', '평일 예약하기'처럼 무엇이 나오는지 알 수 있게 씁니다.
  6. 메뉴 경로를 정리하고 싶다면 이동 경로(브레드크럼) 글처럼 상위 메뉴로 돌아가는 길도 함께 만듭니다.
  7. 고친 페이지는 URL 검사로 구글이 새 링크를 볼 수 있는지 확인합니다.
모든 페이지 바닥글에 링크를 수십 개씩 몰아넣는 것은 해결책이 아닙니다. 손님이 읽기 어려워지고 정작 중요한 링크가 묻힙니다. 꼭 필요한 페이지 몇 개에 문맥에 맞는 링크를 거는 것이 낫습니다.

6링크를 사면 안 되는 이유는 무엇인가요?

'백링크 수백 개 작업' 같은 광고 문자를 받는 사장님이 많습니다. 검색 순위를 올리려고 돈을 주고 링크를 사고파는 것은 구글 검색 스팸 정책에서 금지하는 행동입니다. 자세한 내용은 같은 날 올린 검색 스팸 정책 글에서 다루므로 여기서는 짧게만 정리합니다.

  • 링크를 사지 않습니다. 링크 교환을 조건으로 한 제안도 받지 않습니다.
  • 링크 보고서에 처음 보는 사이트가 많이 보인다고 해서 바로 문제가 있다는 뜻은 아닙니다.
  • 자연스러운 링크는 거래처 소개, 지역 행사 참여, 손님이 쓴 블로그 후기처럼 실제 관계에서 생깁니다.

결국 다른 사이트가 링크를 걸고 싶어지는 페이지는 메뉴 · 가격 안내 · 오시는 길이 정확하고 휴대폰에서 잘 열리는 페이지입니다. 우리 홈페이지의 기본 상태가 궁금하다면 무료 SEO 점검에 주소를 넣어 보세요. 큰길브리지는 홈페이지 제작과 내부 링크 정리를 전국 비대면으로 진행합니다.

자주 묻는 질문

링크 보고서에 외부 링크가 하나도 없으면 문제인가요?

새 홈페이지라면 흔한 일입니다. 보고서에는 Google 이 시간이 지나면서 찾은 링크가 들어가고, 모든 링크를 다 담은 목록도 아닙니다. 거래처 · 지역 단체 소개처럼 자연스러운 링크가 생기면 차차 보일 수 있습니다.

표가 1,000행에서 끝나는데 나머지는 어떻게 보나요?

보고서 표는 최대 1,000행까지 보입니다. 내보내기 버튼을 쓰면 최대 100,000행까지 받을 수 있습니다.

www 가 붙은 주소와 안 붙은 주소가 따로 나오지 않는 이유는 무엇인가요?

상위 링크 사이트 표는 루트 도메인 단위로 묶어서 보여 줍니다. www.example.com 에서 온 링크도 example.com 으로 묶여 나옵니다.

내부 링크는 많을수록 좋은가요?

숫자를 늘리는 것보다 손님이 꼭 봐야 할 페이지가 첫 화면 · 메뉴 · 관련 페이지에서 연결돼 있는지가 중요합니다. 바닥글에 링크를 몰아넣는 것보다 문맥에 맞는 링크 몇 개가 낫습니다.

백링크를 늘려 준다는 업체에 맡겨도 되나요?

검색 순위를 올리려고 링크를 사고파는 것은 구글 검색 스팸 정책에서 금지하는 행동입니다. 돈을 주고 링크를 사지 않는 것이 안전합니다.
