공유 미리보기카카오톡 미리보기og:title캐시 초기화

공유 미리보기를 고쳤는데 카카오톡에 예전 제목과 사진이 그대로 뜬다면, 홈페이지가 아니라 카카오 · 페이스북 서버에 남은 기억(캐시)이 문제일 때가 많습니다. 태그를 고친 뒤에는 각 회사의 공식 도구로 그 주소의 캐시를 지워야 새 내용이 반영됩니다. 이 글은 제목 · 설명 문구를 쓰는 법과 초기화 순서, 페이지마다 다른 미리보기를 만드는 법을 다룹니다. 이미지 크기는 썸네일 규격 글에 따로 정리해 두었습니다.

핵심만 먼저
  • 미리보기의 제목 · 설명 · 사진은 페이지 머리말의 og:title · og:description · og:image 값으로 정해집니다.
  • 카카오는 OG 태그를 바꾼 뒤 'URL 메타정보 관리' 도구에서 캐시를 초기화해야 이후 공유에 반영된다고 안내합니다.
  • Facebook은 공유 디버거(Sharing Debugger)로 페이지를 다시 읽게 하고, 이미지는 주소가 바뀌어야 새로 가져갑니다.
  • 모든 페이지가 첫 화면의 OG 태그를 복사해 쓰면 어떤 주소를 보내도 미리보기가 똑같이 나옵니다.

1미리보기의 제목 · 설명 · 사진은 어디서 오나요?

카카오톡 · 페이스북은 주소를 받으면 그 페이지를 한 번 읽어 가서 머리말의 Open Graph(OG) 태그를 꺼내 씁니다. OG 태그는 '이 페이지를 공유하면 이렇게 보여 달라'는 메모라고 생각하면 됩니다. 태그가 없으면 Meta 문서 설명대로 크롤러가 제목 · 설명 · 사진을 짐작해서 고릅니다.

태그공식 문서 설명사장님이 적을 내용
og:title사이트 이름 같은 꾸밈 없이 글 제목(Meta)그 페이지가 무엇인지 한 줄
og:description짧은 설명(ogp.me 1~2문장, Meta 2~4문장)누구에게 무엇을 · 어떻게 연락하는지
og:url대표 주소, 꼬리표 없는 주소(Meta)그 페이지 자기 주소
og:image공유될 때 보이는 이미지 주소크기는 썸네일 규격 글 참고
og:site_name더 큰 사이트의 이름(ogp.me)가게 이름

2og:title · og:description은 어떻게 써야 눌리나요?

Meta 문서는 og:title에 사이트 이름 같은 꾸밈을 빼라고 하고, 가게 이름은 og:site_name에 따로 두게 되어 있습니다. 아래는 공식 기준이 아니라 일반적인 문구 요령입니다.

  • 제목은 페이지마다 다르게 — '○○미용실'보다 '○○미용실 11월 예약 안내'처럼 무슨 페이지인지 보이게 씁니다.
  • 설명 첫 문장에 핵심 — 채팅방에서는 설명이 잘려 보일 수 있으니 앞부분에 위치 · 대상 · 연락 방법을 둡니다.
  • 사진 속 글자와 겹치지 않게 — 사진에 이미 적힌 문구를 제목에 또 쓰면 같은 말이 두 번 보입니다.
  • 과장 표현 빼기 — 미리보기도 광고 문구입니다. 페이지에 없는 할인 · 혜택을 적지 않습니다.

3고쳤는데도 예전 미리보기가 뜨면 무엇부터 하나요?

  1. 페이지를 열고 소스 보기로 og 태그가 실제로 바뀌었는지, 같은 태그가 두 번 들어가 있지 않은지 봅니다.
  2. 카카오: Kakao Developers의 '카카오톡 URL 메타정보 관리' 도구에서 주소를 넣고 [메타 정보 조회] → [캐시 초기화]를 누른 뒤 다시 조회합니다. 도구를 열면 카카오 계정 로그인 화면이 먼저 나옵니다.
  3. Facebook: 공유 디버거에 주소를 넣어 다시 읽게 하고, 경고 항목이 있는지 봅니다.
  4. 사진이 그대로면 같은 이름으로 덮어쓰지 말고 새 파일 이름으로 올립니다. Meta 문서는 이미지가 주소 단위로 저장되어 주소가 바뀌어야 갱신된다고 적습니다.
  5. 그래도 내 휴대폰에서만 예전 사진이 보이면 카카오톡 앱 쪽 캐시일 수 있습니다. 카카오 데브톡 답변은 미리보기 이미지가 이용자의 카카오톡에도 저장되므로 앱 캐시를 지우고 다시 실행하라고 안내합니다.
카카오 문서에 따르면 서버 방화벽이 카카오 스크랩 서버의 접근을 막으면 이미지가 아주 느리게 오거나 표시되지 않을 수 있습니다. 호스팅 업체의 보안 설정도 함께 확인하십시오.

4페이지마다 다른 미리보기는 어떻게 만드나요?

홈페이지 제작 도구에서 머리말을 한 번만 설정하면 모든 페이지가 같은 OG 태그를 물려받는 경우가 많습니다. 그러면 이벤트 공지를 보내도 첫 화면 미리보기가 뜹니다. Meta 문서는 주소 하나를 대상 하나로 보고, og:url에 그 페이지의 대표 주소를 적으라고 합니다. 이 값이 첫 화면 주소로 고정되어 있으면 공유가 첫 화면으로 모입니다.

페이지og:title 예og:image 예
첫 화면가게 이름 + 하는 일매장 대표 사진
메뉴 · 서비스서비스 이름 + 지역그 서비스 사진
이벤트 공지행사 이름 + 날짜행사용 사진(새 파일 이름)
오시는 길가게 이름 + 위치 안내외관 · 간판 사진
공지 페이지를 새로 만들 때마다 위 세 칸(og:title · og:url · og:image)만 바꿔도 미리보기가 구분됩니다. 미리보기를 눌러 들어온 손님이 바로 문의하게 하려면 카카오톡 채널 연결 글도 참고하십시오.

5공유하기 전에 무엇을 확인하나요?

  • 보낼 페이지 주소를 카카오 도구 · 공유 디버거에 넣어 제목 · 설명 · 사진을 미리 봅니다.
  • http · https, 끝의 '/' 유무가 다른 주소를 섞어 보내지 않고 한 가지로 통일합니다.
  • 사진을 바꾼 날에는 새 파일 이름으로 올렸는지 다시 봅니다.

우리 홈페이지에 OG 태그가 페이지마다 들어가 있는지는 무료 SEO 점검으로 확인할 수 있습니다. 미리보기까지 챙긴 홈페이지나 랜딩페이지가 필요하다면 제작 문의에 남겨 주십시오. 전국 비대면으로 진행합니다.

자주 묻는 질문

카카오 캐시 초기화를 했는데도 예전 사진이 보여요.

Meta 문서처럼 이미지는 주소 기준으로 기억되는 경우가 많으니 새 파일 이름으로 올린 뒤 다시 초기화해 보십시오. 내 휴대폰에서만 그렇다면 카카오 데브톡 답변대로 카카오톡 앱 캐시를 지우고 다시 실행합니다.

카카오 URL 메타정보 관리 도구는 누구나 쓸 수 있나요?

도구 주소를 열면 카카오 계정 로그인 화면으로 넘어갑니다. 로그인 뒤 Kakao Developers 도구 메뉴에서 주소를 조회하고 캐시를 초기화합니다.

og:title과 페이지 제목(title)은 같아야 하나요?

같아도 되지만 꼭 같을 필요는 없습니다. Meta 문서는 og:title에 사이트 이름 같은 꾸밈을 빼라고 안내하므로, 검색용 제목보다 짧게 쓰는 경우가 많습니다.

공유 미리보기 사진 크기는 얼마가 좋나요?

권장 크기와 비율은 큰길브리지 칼럼의 썸네일 규격 글에 공식 문서 기준으로 정리해 두었습니다.
