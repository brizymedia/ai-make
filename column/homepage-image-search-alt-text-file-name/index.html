홈페이지 이미지 검색에 메뉴 · 시공 · 상품 사진이 잘 나오게 하는 핵심은 세 가지입니다. 사진마다 무엇이 보이는지 대체 텍스트(alt)로 적고, 파일 이름을 뜻이 있는 이름으로 바꾸고, 사진을 그 사진을 설명하는 글 바로 옆에 두는 것입니다. Google Search Central의 이미지 SEO 안내는 대체 텍스트를 이미지 메타데이터 가운데 가장 중요한 속성으로 꼽습니다. 여기에 지원 형식과 반응형 이미지 설정, 검색 결과 옆 작은 아이콘(파비콘)까지 함께 정리했습니다.

핵심만 먼저
  • 대체 텍스트(alt)는 Google이 이미지 메타데이터 중 가장 중요하게 보는 속성입니다. 키워드를 넣되 사진 내용을 쓸모 있게 설명해야 합니다(Google 안내 요지).
  • 파일 이름은 IMG00023.JPG보다 my-new-black-kitten.jpg처럼 내용을 알려 주는 이름이 낫고, image1.jpg · pic.gif 같은 이름은 피합니다(Google 안내 요지).
  • 사진은 관련 글 가까이에 둡니다. 메뉴 사진은 메뉴 설명 옆, 시공 사진은 시공 내용 옆입니다.
  • 반응형 이미지(srcset)를 써도 img 요소의 src 속성에 기본 주소를 꼭 넣습니다. Google은 src 속성에서 이미지를 찾습니다.
  • 파비콘은 정사각형, 최소 8x8px이며 48x48px보다 큰 크기가 권장됩니다. 다 지켜도 표시가 보장되지는 않습니다(Google 안내 요지).

1홈페이지 이미지 검색은 사장님 가게에 왜 중요한가요?

손님은 글보다 사진으로 가게를 고르는 경우가 많습니다. '단체 상차림', '욕실 리모델링', '수제 케이크'처럼 검색한 뒤 이미지 탭을 눌러 사진부터 훑어보고, 마음에 드는 사진을 눌러 그 홈페이지로 들어옵니다(일반 요령). 그런데 홈페이지에 사진만 올려 두고 아무 설명도 없으면 검색엔진은 그 사진이 무엇인지 알기 어렵습니다.

Google Search Central의 'Google 이미지 SEO 권장사항' 문서(영문 원문을 우리말로 풀어 옮긴 요지)는 이미지가 무엇인지 알려 주는 단서로 대체 텍스트, 파일 이름, 주변 글, 이미지 주소를 차례로 안내합니다. 아래에서 하나씩 사장님 홈페이지에 맞춰 봅니다.

2대체 텍스트(alt)는 어떻게 써야 하나요?

대체 텍스트(alt)는 사진이 안 보일 때 대신 보여 주는 글이자, 화면 낭독기가 시각장애인에게 읽어 주는 글입니다. Google 안내 요지는 이렇습니다. 대체 텍스트는 이미지 메타데이터 가운데 가장 중요한 속성이고, 키워드를 적절히 쓰되 유용하고 정보가 풍부한 내용이어야 합니다. 키워드만 줄줄이 늘어놓는 것은 좋지 않습니다.

사진아쉬운 대체 텍스트나은 대체 텍스트(일반 요령)
식당 메뉴메뉴뚝배기에 담긴 순두부찌개와 반찬 네 가지
인테리어 시공시공사진1타일을 새로 깐 아파트 욕실, 시공 후 모습
상품케이크 케이크 수제케이크 맛집딸기를 올린 2단 생크림 케이크
가게 외관(비워 둠)1층 유리문과 초록 간판이 있는 가게 입구
일반 요령 — 전화로 친구에게 사진을 설명한다고 생각하고 한 문장으로 씁니다. 장식용 선 · 배경 무늬처럼 뜻이 없는 그림은 굳이 설명을 길게 달지 않아도 됩니다. 배너 · 버튼 · 배경 사진별로 어떻게 정하는지는 이미지 대체 텍스트 정하는 법 글에 따로 정리했습니다.

3사진 파일 이름은 왜 바꿔야 하나요?

휴대폰으로 찍은 사진은 IMG_0023.JPG, KakaoTalk_2026… 같은 이름으로 저장됩니다. Google 안내 요지는 파일 이름도 이미지 내용을 알려 주는 단서가 될 수 있다는 것입니다. 예로 my-new-black-kitten.jpg가 IMG00023.JPG보다 낫다고 들고, image1.jpg · pic.gif · 1.jpg 같은 일반적인 이름은 피하라고 안내합니다.

  1. 올리기 전에 이름을 바꿉니다. 홈페이지 관리 화면에 올린 뒤에는 바꾸기 번거로운 경우가 많습니다(일반 요령).
  2. 보이는 것을 영어 소문자로 짧게 적습니다. 예: sundubu-jjigae-set.jpg, bathroom-tile-remodel-after.jpg, strawberry-cream-cake.jpg(일반 요령).
  3. 낱말 사이는 하이픈(-)으로 잇습니다. 띄어쓰기는 주소에서 %20 같은 기호로 바뀌어 읽기 어렵습니다(일반 요령).
  4. 같은 이름에 숫자만 붙이지 않습니다. cake1, cake2 대신 cake-slice, cake-whole처럼 차이를 적습니다(일반 요령).

4사진은 어디에, 어떤 형식으로 올려야 하나요?

Google 안내 요지는 이미지를 관련 글 가까이에 두라는 것입니다. 사진 바로 위 · 아래 글이 그 사진이 무엇인지 알려 주는 단서가 되기 때문입니다. 메뉴 사진 모음만 한 페이지에 몰아 두기보다 메뉴 이름 · 재료 설명 옆에 각각 두는 편이 낫습니다.

점검 항목Google 안내 요지사장님이 할 일
사진 위치이미지는 관련 글 가까이 배치사진 아래에 한두 줄 설명을 붙입니다
지원 형식BMP, GIF, JPEG, PNG, WebP, SVG, AVIF휴대폰 사진(HEIC 등)은 JPEG나 WebP로 바꿔 올립니다
이미지 찾는 곳Google은 img 요소의 src 속성에서 이미지를 찾음사진을 CSS 배경으로만 넣지 말고 img 태그로 넣습니다
반응형 이미지srcset을 써도 src 속성에 대체 URL을 항상 지정제작자에게 src가 비어 있지 않은지 확인합니다

반응형 이미지는 휴대폰에는 작은 사진, PC에는 큰 사진을 골라 보여 주는 방식입니다. 이때 코드 모양은 대략 img src="cake-800.jpg" srcset="cake-400.jpg 400w, cake-800.jpg 800w" alt="딸기를 올린 2단 생크림 케이크" 처럼 됩니다. 핵심은 srcset이 있어도 src 칸을 비우지 않는 것입니다.

일반 요령 — 사진을 슬라이드 배경이나 CSS 배경으로만 넣은 홈페이지가 많습니다. 보기에는 똑같아도 img 요소가 아니면 Google이 이미지로 찾기 어렵습니다. 검색에 나오게 하고 싶은 메뉴 · 시공 · 상품 사진은 img 요소로 넣습니다.

5검색 결과 옆 작은 아이콘(파비콘)은 어떻게 정하나요?

파비콘은 브라우저 탭과 Google 검색 결과에서 사이트 이름 옆에 보이는 작은 아이콘입니다. Google Search Central의 '검색 결과에 표시할 파비콘 정의' 문서 요지를 정리하면 아래와 같습니다.

  • 모양 — 정사각형(1:1)이어야 하고 최소 8x8px입니다. 48x48px보다 큰 파비콘을 권장합니다.
  • 넣는 곳 — 홈페이지 머리말(head)에 link rel="icon" href="/path/to/favicon.ico" 형태로 지정합니다.
  • 개수 — 사이트(호스트 이름)당 파비콘 하나만 지원합니다.
  • 주소 — 파비콘 URL은 자주 바꾸지 말고 안정적으로 유지합니다.
  • 형식 — BMP, GIF, ICO, PNG, JPEG, PPM, TIFF 등을 지원합니다.
  • 반영 시간 — 크롤링되어 바뀌기까지 며칠에서 몇 주가 걸릴 수 있고, 지침을 다 지켜도 표시가 보장되지는 않습니다.
일반 요령 — 가게 로고를 그대로 줄이면 글자가 뭉개집니다. 로고에서 첫 글자나 상징 하나만 떼어 정사각형으로 만든 뒤, 작게 줄였을 때도 알아보이는지 확인합니다.

6우리 홈페이지 사진은 지금 어떤 상태인가요?

가장 쉬운 확인법은 대표 사진 하나를 골라 이름과 설명을 살펴보는 것입니다. 파일 이름이 숫자뿐인지, 대체 텍스트가 비어 있는지, 사진 옆에 설명 글이 있는지 세 가지만 봐도 홈페이지 이미지 검색 준비 상태를 대략 알 수 있습니다(일반 요령). 한꺼번에 확인하고 싶다면 무료 SEO 점검을 먼저 받아 보세요.

큰길브리지는 홈페이지 제작을 전국 비대면으로 진행합니다. 메뉴 · 시공 · 상품 사진을 대체 텍스트와 파일 이름까지 정리해 다시 올리고 싶다면 제작 문의에 남겨 주세요.

자주 묻는 질문

대체 텍스트에 키워드를 많이 넣으면 홈페이지 이미지 검색에 더 잘 나오나요?

Google은 키워드를 적절히 쓰되 유용하고 정보가 풍부한 내용으로 쓰라고 안내합니다. 키워드를 나열하기보다 사진에 보이는 것을 한 문장으로 설명하는 편이 낫습니다.

사진 파일 이름을 한글로 써도 되나요?

Google 안내 예시는 my-new-black-kitten.jpg처럼 내용을 알려 주는 이름입니다. 주소에서 한글이 기호로 바뀌어 보이는 경우가 있어 영어 소문자와 하이픈으로 짓는 편이 관리하기 쉽습니다(일반 요령).

Google 이미지 검색에서 지원하는 사진 형식은 무엇인가요?

Google 안내에 따르면 BMP, GIF, JPEG, PNG, WebP, SVG, AVIF 형식을 지원합니다.

파비콘을 바꿨는데 검색 결과에 바로 안 보여요.

Google은 크롤링되어 반영되기까지 며칠에서 몇 주가 걸릴 수 있고, 지침을 다 지켜도 표시가 보장되지는 않는다고 안내합니다. 파비콘 주소는 자주 바꾸지 않는 것이 좋습니다.
