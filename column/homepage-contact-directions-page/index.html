오시는 길 페이지홈페이지 지도 넣기구글 지도 퍼가기카카오맵 길찾기 링크

오시는 길 페이지는 지도 한 장보다 '글자로 적은 주소'가 먼저입니다. 주소 · 건물 이름 · 층을 글자로 적어 두면 손님이 검색하고 복사할 수 있고, 그 아래 지도와 대중교통 · 주차 안내, 휴대폰에서 바로 열리는 길찾기 버튼을 붙이면 됩니다. 지도 넣는 법은 구글 지도 고객센터와 카카오 지도 API 가이드를 직접 열어 확인했습니다.

핵심만 먼저
  • 주소는 사진이나 지도 이미지가 아니라 글자로 적어야 손님이 길게 눌러 복사하고 지도 앱에 붙여 넣을 수 있습니다(일반 요령).
  • 구글 지도는 컴퓨터에서 메뉴 → '지도 공유 또는 퍼가기' → '지도 퍼가기'에서 HTML을 복사해 홈페이지에 넣을 수 있다고 고객센터가 안내합니다.
  • 카카오 지도를 코드로 띄우려면 카카오 개발자사이트에서 JavaScript 키를 받고 사이트 도메인을 등록해야 하며, 등록한 도메인에서만 지도 API가 동작합니다.
  • 길찾기 버튼은 지도를 코드로 띄우지 않아도 됩니다. 카카오는 map.kakao.com/link/to/, 구글은 google.com/maps/dir/?api=1 주소 형식을 공개해 두었습니다.
  • 대중교통 · 주차 안내는 '가장 가까운 역 · 출구 · 정류장'과 '주차 가능 여부 · 위치'를 짧은 표로 적으면 휴대폰에서 읽기 쉽습니다(일반 요령).

1오시는 길 페이지에는 무엇이 들어가야 하나요?

손님이 이 페이지를 여는 순간은 대개 출발 직전이거나 이미 근처에 와 있을 때입니다. 그래서 순서가 중요합니다. 아래 표는 공식 기준이 아니라 일반 요령으로 정리한 기본 구성입니다.

순서넣을 것이유
1주소(도로명) · 건물 이름 · 층 · 호수검색 · 복사가 되고, 지도가 안 떠도 길을 찾을 수 있다
2전화 버튼 · 영업시간길을 잃었을 때 바로 묻는다
3지도(구글 퍼가기 또는 카카오맵)위치를 한눈에 본다
4길찾기 버튼(카카오맵 · 구글 지도)휴대폰에서 지도 앱으로 바로 넘어간다
5대중교통 · 주차 안내출발 전에 교통수단을 고른다
6건물 입구 · 엘리베이터 안내건물 앞에서 헤매지 않는다

건물 안 승강기 · 층 안내는 상가 매장 오시는 길 글에, 고속도로 IC · 요금소 이름 적는 법은 IC 이름 글에 따로 정리했으니 여기서는 되풀이하지 않습니다.

2주소는 왜 꼭 글자로 적어야 하나요?

약도 그림이나 지도 캡처에만 주소가 들어 있으면 손님은 그 주소를 복사할 수 없고, 검색 엔진도 그 글자를 읽기 어렵습니다. 아래는 일반 요령입니다.

  • 도로명 주소를 한 줄로 적고, 그 아래 건물 이름 · 층 · 호수를 따로 적습니다.
  • 네이버 · 구글 업체 정보, 명함, 홈페이지 맨 아래(푸터)의 주소와 글자 하나까지 같게 맞춥니다.
  • '○○은행 건너편'처럼 눈에 띄는 기준점을 한 줄 덧붙입니다. 바뀔 수 있는 가게 이름보다 오래 있을 건물 · 역 이름이 낫습니다.
업체 정보마다 주소가 다르게 적혀 있으면 손님도 헷갈립니다. 맞추는 순서는 스마트플레이스 · 구글 프로필 글을 참고하세요.

3지도는 어떻게 넣나요? 구글 지도와 카카오맵

구글 지도 고객센터의 '경로 공유, 전송 또는 인쇄' 도움말은 컴퓨터에서 Google 지도를 열고 공유할 부분으로 이동한 뒤, 왼쪽 위 메뉴에서 '지도 공유 또는 퍼가기'를 누르고 '지도 퍼가기'에서 HTML을 복사하라고 안내합니다. 이 HTML을 홈페이지 편집기의 HTML 넣기 칸에 붙이면 됩니다. 같은 도움말은 저장된 위치나 거리 측정이 들어간 지도는 공유할 수 없다고 적었습니다.

카카오 지도 Web API 가이드는 지도를 띄우려면 키 발급이 필요하다고 안내합니다. 카카오 개발자사이트에서 앱을 만들고 JavaScript 키를 고른 뒤 JavaScript SDK 도메인을 등록하며, 등록된 사이트 도메인에서만 지도 API를 쓸 수 있으니 반드시 등록하라고 적었습니다.

  1. 코드가 낯설면 구글 지도 '지도 퍼가기' HTML 복사가 가장 간단합니다.
  2. 카카오맵을 띄우려면 카카오 개발자사이트에서 앱 생성 → JavaScript 키 확인 → 홈페이지 주소(도메인) 등록 순서로 준비합니다.
  3. 홈페이지 주소를 바꾸면(예: 새 도메인 연결) 카카오에 등록한 도메인도 함께 고칩니다. 안 고치면 새 주소에서 지도가 뜨지 않을 수 있습니다.
  4. 지도를 넣은 뒤 휴대폰에서 지도가 화면 너비에 맞는지, 손가락으로 쓸 때 페이지 스크롤을 막지 않는지 확인합니다(일반 요령).
지도가 안 뜨는 날에도 길을 찾을 수 있게, 지도는 글자 주소 '아래'에 둡니다. 지도만 있고 주소 글자가 없는 페이지는 피하세요(일반 요령).

4휴대폰 길찾기 버튼은 어떻게 만드나요?

지도를 코드로 띄우지 않아도, 정해진 주소 형식의 링크만으로 지도 앱의 길찾기를 열 수 있습니다. 두 회사가 공개한 형식은 아래와 같습니다.

지도주소 형식공식 문서 설명
카카오맵https://map.kakao.com/link/to/이름,위도,경도도착지를 이름과 좌표 또는 장소ID로 지정. 이동수단은 car · traffic · walk · bicycle
구글 지도https://www.google.com/maps/dir/?api=1&destination=주소api=1은 모든 요청에 필요. destination은 장소 이름 · 주소 · 좌표, 문자열은 URL 인코딩

구글 문서에 따르면 destination이 없으면 사용자가 목적지를 직접 입력하는 빈 양식이 나올 수 있고, travelmode를 지정하지 않으면 관련성이 높은 이동 방법이 표시됩니다. 카카오 가이드는 대중교통(traffic)은 경유지를 지정할 수 없다고 적었습니다.

버튼은 '카카오맵으로 길찾기' · '구글 지도로 길찾기'처럼 글자로 무엇이 열리는지 알려 주고, 손가락으로 누르기 넉넉한 크기로 만듭니다(일반 요령). 버튼 크기 기준은 모바일 전화 버튼 글에 정리했습니다.

5대중교통 · 주차 안내는 어떻게 적나요?

아래는 일반 요령입니다. 길게 쓰기보다 손님이 고르는 기준대로 나눕니다.

  • 지하철: 역 이름 · 출구 번호 · 걸어서 걸리는 시간(직접 걸어 보고 적기).
  • 버스: 가까운 정류장 이름과 그 정류장에 서는 노선 번호.
  • 주차: 주차 가능 여부, 주차장 위치(건물 뒤 · 지하 등), 무료 여부는 바뀔 수 있으니 '방문 전 전화 확인' 문구를 함께.
  • 주차가 안 되면 가까운 공영주차장 이름을 적되, 운영 조건은 해당 주차장 안내를 보라고 적습니다.

다 만든 뒤 오시는 길 페이지를 휴대폰으로 열어 주소 복사 → 길찾기 버튼 → 전화 버튼을 한 번씩 눌러 보세요. 검색에 주소가 잘 읽히는지는 무료 SEO 점검으로 확인할 수 있습니다.

자주 묻는 질문

지도만 넣으면 주소는 안 적어도 되나요?

지도는 안 뜰 수도 있고, 지도 속 글자는 복사하기 어렵습니다. 일반 요령으로는 주소 · 건물 이름 · 층을 글자로 먼저 적고 지도는 그 아래에 둡니다.

카카오맵이 우리 홈페이지에서만 안 떠요.

카카오 지도 Web API 가이드는 등록된 사이트 도메인에서만 지도 API를 쓸 수 있다고 안내합니다. 카카오 개발자사이트에 지금 홈페이지 주소가 등록돼 있는지 먼저 확인하세요.

길찾기 버튼을 만들려면 지도 API 키가 필요한가요?

카카오 가이드의 길찾기 바로가기(map.kakao.com/link/to/)와 구글 지도 URL(google.com/maps/dir/?api=1)은 정해진 형식의 링크입니다. 지도를 화면에 띄우는 것과 달리 링크만 거는 방식입니다.

구글 지도 퍼가기에서 저장한 장소가 든 지도는 왜 안 되나요?

구글 지도 도움말은 저장된 위치가 포함된 지도, 거리 측정이 포함된 지도는 공유할 수 없다고 적었습니다. 가게 위치만 검색해 띄운 상태에서 퍼가기를 하세요.
