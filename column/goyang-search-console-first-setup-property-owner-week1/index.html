고양 서치콘솔 설정을 처음 한다면 순서는 세 가지입니다. 도메인 구입처에 로그인할 수 있으면 도메인 속성으로 만들고, 소유자는 사장님 본인 구글 계정으로 두고 제작사에는 사용자 권한만 주며, 첫 주에는 사이트맵 · 직접 조치 보고서를 먼저 보고 검색 실적은 며칠 뒤에 봅니다. 구글 도움말은 속성을 추가하면 며칠 후 데이터가 표시되기 시작한다고 안내하므로, 행사나 개업 전에 미리 등록해 두는 편이 낫습니다.

핵심만 먼저
  • 도메인 속성은 www · m 같은 하위 도메인과 http · https를 모두 묶지만 DNS 레코드로만 확인할 수 있습니다.
  • URL 접두어 속성은 적은 주소로 시작하는 URL만 포함하며 HTML 파일 · 태그 등 여러 방법으로 확인할 수 있습니다.
  • 소유자는 사용자 추가 · 삭제와 설정 변경까지 할 수 있으니, 사장님 계정을 소유자로 두고 외부 업체에는 전체 · 제한된 권한을 주는 편이 안전합니다.
  • 속성을 추가하면 며칠 후 데이터가 보이기 시작하고, 사이트맵은 제출 즉시 구글이 가져갑니다.

1도메인 속성과 URL 접두어, 무엇으로 시작하나요?

서치콘솔에서 '속성'은 데이터를 모아 볼 사이트 단위입니다. 구글 도움말이 안내하는 유형은 두 가지이고, 처음 고를 때 아래 표로 정하면 됩니다.

구분도메인 속성URL 접두어 속성
입력 예example.com (https · www 없이)https://www.example.com/
포함 범위모든 하위 도메인 + http · https적은 주소로 시작하는 URL만
확인 방법DNS 레코드만HTML 파일 · 태그 · 애널리틱스 · 태그 관리자 · DNS
어울리는 경우도메인 구입처에 로그인할 수 있을 때DNS를 못 만지고 홈페이지 코드만 넣을 수 있을 때
둘 다 만들어도 됩니다. 계정당 최대 1,000개까지 속성을 추가할 수 있어, 도메인 속성으로 전체를 보고 필요하면 URL 접두어 속성으로 특정 경로만 따로 볼 수 있습니다.

2소유권 확인은 우리 홈페이지 상황에서 무엇이 쉬운가요?

확인 방법별 설명은 인천 구글 노출 글에 표로 정리해 두었습니다. 여기서는 처음 하는 분이 자주 막히는 지점만 짚습니다.

  • DNS TXT 레코드 — 도메인 구입처 DNS 설정에 google-site-verification=로 시작하는 값을 넣습니다. 반영까지 최대 2~3일이 걸릴 수 있어, 실패하면 1~2일 뒤 다시 시도합니다. 확인 뒤에도 지우지 않습니다. DNS 화면이 낯설다면 광주 도메인 연결 글을 먼저 보세요.
  • HTML 파일 — 이름 · 내용을 바꾸지 않고 사이트 맨 위 폴더에 올립니다. 로그인하지 않은 시크릿 창에서 열려야 합니다.
  • 메타 태그 — 로그인하지 않은 사람이 보는 첫 화면의 head 안에 넣고, 페이지 소스에서 google-site-verification을 찾아 실제로 들어갔는지 봅니다. 빌더의 미리보기 사본만 고치고 게시를 안 한 경우가 흔합니다.

구글은 방법 하나가 실패할 때를 대비해 두 가지 이상 추가해 두기를 권합니다.

3계정은 누구 이름으로 두어야 하나요?

제작사가 자기 계정으로 등록해 주고 끝나는 경우가 있습니다. 나중에 업체를 바꾸면 데이터를 볼 길이 막힙니다. 구글 도움말의 권한 표는 아래와 같습니다.

권한할 수 있는 일누구에게
소유자사용자 추가 · 삭제, 설정 변경, 모든 데이터와 도구사장님 본인 구글 계정
전체 권한 사용자모든 데이터 보기, 사이트맵 제출 등 일부 작업관리를 맡긴 제작사
제한된 권한 사용자대부분의 데이터 보기만숫자만 보면 되는 직원
확인된 소유자가 모두 권한을 잃으면 다른 사용자도 모두 접근할 수 없게 됩니다. 확인용 파일 · 태그 · DNS 값은 리뉴얼 때도 지우지 않습니다. 사용자는 설정 > 사용자 및 권한에서 소유자만 추가할 수 있습니다.

4고양 킨텍스 박람회 전에 만든 홈페이지라면?

고양시 일산서구 킨텍스로 217-60에 있는 킨텍스 누리집에는 11월 12~15일 '메가푸드쇼 2026', 11월 26~29일 '제55회 맘앤베이비엑스포' 같은 일정이 올라와 있습니다. 부스에서 명함 · QR로 홈페이지를 알릴 계획이라면, 데이터가 쌓이는 데 며칠이 걸리니 행사 1~2주 전에 속성을 만들어 두면 행사 주간 검색 유입을 비교해 볼 수 있습니다.

공공데이터포털에는 고양시가 올린 '경기도 고양시_소상공인 지원사업' 데이터(2026-06-11 등록)가 있습니다. 사업명 · 지원대상 · 지원내용 · 신청 기간 · 수탁기관을 담은 목록이라, 홈페이지 홍보와 함께 쓸 지원사업이 있는지 볼 때 참고할 수 있습니다. 세부 조건은 시 공고 원문으로 확인하세요.

5첫 7일, 어떤 순서로 보나요?

  1. 1일째: 속성을 만들고 소유권을 확인한 뒤, 제작사 계정을 전체 권한 사용자로 추가합니다.
  2. 1일째: 사이트맵 보고서에 sitemap.xml 주소를 넣습니다. 구글은 제출 즉시 가져가고, 상태가 '성공'이면 됩니다. '가져올 수 없음'이면 안산 사이트맵 글의 점검 순서를 봅니다.
  3. 2~3일째: 직접 조치 보고서를 엽니다. 적용된 조치가 없으면 녹색 체크가 보이고, 조치가 있으면 이 보고서와 메시지 센터로 알려 줍니다.
  4. 3~7일째: 실적 보고서에 클릭수 · 노출수가 들어오기 시작합니다. 가장 최근 값은 예비 데이터라 점선으로 표시되고 바뀔 수 있습니다. 숫자 읽는 법은 대구 방문자 분석 글에 있습니다.
  5. 7일째 이후: 특정 페이지가 안 보이면 URL 검사로, 색인 안 된 이유가 쌓이면 연말 점검표 글의 페이지 색인 보고서 부분을 봅니다.

6며칠이 지나도 데이터가 없다면?

구글 도움말은 확인 후 며칠이 지나도 데이터가 없으면 사이트가 아직 검색에 나오지 않았거나, http와 https를 혼동하는 등 주소를 잘못 입력했을 수 있다고 안내합니다. URL 접두어 속성이라면 실제 접속 주소(https인지, www가 붙는지)와 속성 주소가 같은지부터 봅니다.

혼자 확인하기 어렵다면 무료 SEO 점검에서 사이트맵 · robots.txt 상태를 먼저 보세요. 큰길브리지는 홈페이지 제작과 서치콘솔 · 네이버 서치어드바이저 등록을 전국 비대면으로 진행합니다. 새로 만들 계획이라면 제작 문의를 남겨 주세요.

자주 묻는 질문

도메인 속성과 URL 접두어 속성 중 하나만 골라야 하나요?

둘 다 만들 수 있습니다. 도메인 속성은 DNS 레코드로만 확인되니, DNS를 만질 수 없다면 URL 접두어 속성으로 시작하면 됩니다.

제작사가 소유자로 등록했는데 바꿀 수 있나요?

사장님 계정으로 소유권을 직접 확인하면 소유자가 됩니다. 확인된 소유자의 권한은 낮출 수 없고 삭제만 되며, 다시 확인하지 못하게 하려면 그 사람의 확인 토큰도 지워야 합니다.

등록한 날 바로 검색 실적이 보이나요?

구글 도움말은 속성을 추가하면 며칠 후 데이터가 표시되기 시작한다고 안내합니다. 첫날은 소유권 확인과 사이트맵 제출까지 해 두면 됩니다.
