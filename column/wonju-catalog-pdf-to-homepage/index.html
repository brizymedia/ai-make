원주 카탈로그 홈페이지 — 전단지 · 카탈로그 PDF를 웹페이지로 옮기는 순서

원주 카탈로그 홈페이지를 준비한다면 PDF 파일을 그대로 올리는 데서 멈추지 말고, 상품 · 메뉴 단위로 쪼개 글자로 된 웹페이지를 만드는 것이 핵심입니다. 구글은 PDF도 색인할 수 있는 파일 형식으로 안내하지만, 휴대폰에서 손가락으로 확대하며 읽어야 하는 파일과 화면에 맞춰 흐르는 페이지는 손님이 느끼는 편의가 다릅니다. 아래는 공식 문서로 확인한 사실과 일반적인 구성 요령을 나눠 적었습니다.

핵심만 먼저
  • 구글 검색 센터는 PDF(.pdf)를 색인 가능한 파일 형식으로 안내하며, PDF는 사람이 읽을 수 있는 텍스트를 뽑기 위해 별도 파서가 필요한 형식으로 분류합니다.
  • 구글은 스마트폰으로 크롤링한 모바일 버전 콘텐츠로 색인하고 순위를 정하므로, 휴대폰 화면에서 내용이 온전히 보이는지가 중요합니다.
  • PDF 한 덩어리보다 상품군 · 메뉴별로 나눈 페이지가 제목 · 설명을 따로 가질 수 있어 검색어와 맞추기 쉽습니다(일반 요령).
  • 원본 PDF는 지우지 말고 '인쇄용 내려받기' 링크로 남겨 두면 기존 손님과 거래처도 계속 쓸 수 있습니다.
  • 원주시소상공인종합정보센터 누리집에는 10월 1일자로 온라인 입점 교육 공지가 올라와 있어, 홈페이지와 함께 온라인 판로를 준비할 때 참고할 수 있습니다.

1PDF만 올려 두면 무엇이 아쉬운가요?

먼저 오해 하나를 풉니다. PDF가 검색에 아예 안 잡히는 것은 아닙니다. 구글 검색 센터의 '색인 가능한 파일 형식' 문서에는 Adobe PDF가 지원 형식으로 올라 있고, 사람이 읽을 수 있는 텍스트를 뽑으려면 특정 파서가 필요한 형식으로 설명돼 있습니다.

아쉬운 점은 손님 쪽에서 생깁니다. 구글은 스마트폰 에이전트로 크롤링한 모바일 버전 콘텐츠로 색인과 순위를 정한다고 안내합니다. 그런데 A4 크기로 디자인된 카탈로그는 휴대폰에서 글자가 작아 확대 · 이동을 반복해야 하고, 원하는 상품 하나를 찾으려면 수십 쪽을 넘겨야 합니다.

2카탈로그를 어떤 단위로 쪼개야 하나요?

기준은 '손님이 검색창에 치는 말'입니다. 카탈로그 목차를 그대로 메뉴로 쓰기보다, 손님이 실제로 찾는 이름으로 묶어야 페이지마다 제목을 붙이기 쉽습니다. 업종별로 흔한 묶음은 아래와 같습니다(일반 요령).

  • 식당 · 카페 전단지: 대표 메뉴 · 계절 메뉴 · 단체 주문 안내를 각각 한 덩어리로.
  • 제조 · 납품 카탈로그: 제품군별 페이지 하나, 그 안에 규격표와 사진.
  • 학원 · 교습소 안내 책자: 과정별 페이지, 시간표는 표로 따로.
  • 시공 · 인테리어 브로슈어: 공사 종류별 페이지에 사례 사진을 날짜와 함께.

가격이 자주 바뀌는 업종은 가격을 본문 곳곳에 흩어 두지 말고 한 표에 모아 두면 수정할 때 빠뜨리는 곳이 없습니다.

3PDF에서 웹페이지로 옮기는 작업 순서는?

  1. 원본 정리 — 최신 PDF와 원본 디자인 파일, 상품 사진 원본을 한 폴더에 모읍니다. 스캔본이라면 글자를 다시 입력할 준비를 합니다.
  2. 글자 뽑기 — PDF에서 상품명 · 설명 · 규격을 텍스트로 옮깁니다. 그림 안에 박힌 글자는 사람이 직접 다시 칩니다.
  3. 페이지 나누기 — 2장에서 정한 묶음마다 페이지를 하나씩 만들고, 페이지마다 다른 제목과 한두 문장 설명을 씁니다.
  4. 사진 다듬기 — 카탈로그용 고해상도 사진을 화면용 크기로 줄이고, 사진마다 무엇이 보이는지 대체 텍스트를 붙입니다.
  5. 행동 버튼 — 페이지 끝마다 전화 · 문의 · 견적 요청 중 하나를 둡니다.
  6. 원본 남기기 — 인쇄가 필요한 거래처를 위해 PDF는 '전체 카탈로그 내려받기' 링크로 둡니다.
  7. 등록과 확인 — 사이트맵을 다시 제출하고, 휴대폰으로 직접 열어 글자 크기 · 버튼 위치를 확인합니다.

구글 SEO 기본 가이드는 대체 텍스트를 '이미지와 콘텐츠 간의 관계를 설명하는 짧은 텍스트'로 설명합니다. 전단지를 통째로 이미지 한 장으로 올리면 이 설명을 붙일 자리도 하나뿐이라는 점을 기억해 두면 좋습니다.

5옮긴 뒤에는 무엇을 점검하나요?

  • 휴대폰으로 열었을 때 글자를 확대하지 않고 읽히는지

자주 묻는 질문

PDF를 홈페이지에 올리면 구글 검색에 안 나오나요?

나올 수 있습니다. 구글 검색 센터는 PDF를 색인 가능한 파일 형식으로 안내합니다. 다만 휴대폰에서 읽기 불편하고 파일 하나에 제목이 하나뿐이라, 상품별로 나눈 웹페이지를 함께 두는 편이 손님에게 편합니다.

스캔한 전단지 이미지만 있어도 웹페이지로 옮길 수 있나요?

옮길 수 있습니다. 다만 그림 속 글자는 사람이 다시 입력해 텍스트로 만들어야 합니다. 상품명 · 설명 · 연락처처럼 손님이 찾는 글자부터 옮기면 됩니다.

웹페이지로 옮기면 원래 PDF는 지워야 하나요?

지울 필요는 없습니다. 인쇄가 필요한 거래처나 기존 손님을 위해 '전체 카탈로그 내려받기' 링크로 남겨 두고, 내용이 바뀌면 웹페이지와 PDF를 같이 고칩니다.
